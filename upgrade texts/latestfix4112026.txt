## 1.1 — Live TV Audio Flash + Instant Rebuffer — Root Cause Diagnosis Tree

This is almost always one of 5 culprits in MPV-on-Electron setups. Work through them in order:

### CULPRIT A: Hardware Decode Crashing the Video Pipeline

**Symptom:** Audio plays for < 1 second, video never appears, MPV silently restarts or rebuffers.

**Why it happens:** `--hwdec=auto` or `--hwdec=d3d11va` picks a decoder that fails on the stream codec (HEVC, H.264 10-bit, etc.) and MPV falls back mid-stream — but your OSD state machine thinks it's still loading.

**Fix in `electron/mpvManager.cjs` — `loadLiveStream()`:**

```javascript
// REPLACE your current hwdec application logic with this tiered approach:

const hwdecMode = settings?.hwDecoding ?? 'auto-safe';

const hwdecMap = {
  'auto-safe':   'auto-safe',   // MPV's safest auto mode — use this as default
  'auto':        'auto',
  'd3d11va':     'd3d11va',
  'dxva2':       'dxva2',
  'software':    'no',
  'no':          'no',
};

await mpvSetProperty('hwdec', hwdecMap[hwdecMode] ?? 'auto-safe');
```

**Critical:** Change your settings default in `src/types/settings.ts`:
```typescript
hwDecoding: 'auto-safe' as string,  // was probably 'auto' or 'd3d11va'
```

`auto-safe` tells MPV to use hardware decode only when it can guarantee a clean fallback. `auto` on some Windows driver configs silently fails.

### CULPRIT D: Named Pipe IPC Race Condition

**Symptom:** MPV loads, IPC pipe connects, but the first `loadfile` arrives before MPV is fully idle-ready. It plays 0.5s of audio then the demuxer reinitializes.

**Fix — add an MPV readiness gate before sending any stream commands:**

```javascript
// In mpvManager.cjs, replace your current "send when connected" logic:

let mpvReady = false;
let pendingStreamCommand = null;

// In your pipe message handler:
function handleMpvEvent(event) {
  if (event.event === 'idle') {
    mpvReady = true;
    console.log('[MPVManager] MPV confirmed idle-ready');
    if (pendingStreamCommand) {
      executePendingStream();
    }
  }
}

// In loadLiveStream:
async function loadLiveStream(url, settings) {
  if (!mpvReady) {
    console.log('[MPVManager] MPV not ready yet, queuing stream');
    pendingStreamCommand = { type: 'live', url, settings };
    return;
  }
  // ... rest of load logic
}

function executePendingStream() {
  if (!pendingStreamCommand) return;
  const cmd = pendingStreamCommand;
  pendingStreamCommand = null;
  if (cmd.type === 'live') loadLiveStream(cmd.url, cmd.settings);
  if (cmd.type === 'vod') loadVodStream(cmd.url, cmd.startPos, cmd.settings);
}
```

### CULPRIT F: Complete Rebuffering Loop — Add Reconnect Logic

```javascript
// In mpvManager.cjs, add a proper reconnect handler:
let reconnectTimer = null;
let lastStreamUrl = null;
let lastStreamType = null;
let reconnectAttempts = 0;
const MAX_RECONNECT = 5;

function handlePlaybackError(event) {
  if (lastStreamType !== 'live') return;
  if (reconnectAttempts >= MAX_RECONNECT) {
    sendToRenderer('mpv:error', { message: 'Stream unavailable after 5 attempts' });
    reconnectAttempts = 0;
    return;
  }
  
  reconnectAttempts++;
  const delay = Math.min(1000 * reconnectAttempts, 8000); // exponential backoff
  
  console.log(`[MPVManager] Reconnect attempt ${reconnectAttempts} in ${delay}ms`);
  sendToRenderer('mpv:reconnecting', { attempt: reconnectAttempts, delay });
  
  clearTimeout(reconnectTimer);
  reconnectTimer = setTimeout(() => {
    loadLiveStream(lastStreamUrl, lastSettings);
  }, delay);
}

// In your MPV event handler, map end-file reason:
if (event.event === 'end-file') {
  if (event.reason === 'error' || event.reason === 'stop') {
    handlePlaybackError(event);
  } else if (event.reason === 'eof') {
    if (lastStreamType === 'live') handlePlaybackError(event); // live never EOFs legit
  }
}
```

## 1.3 — EPG Guide Not Populating — Fix

The EPG issue is almost always a **channel ID matching failure** between your XMLTV data and your Xtream channel list.

**Step 1 — Add EPG matching diagnostics in `src/services/xmltvEpg.ts`:**

```typescript
// After parsing XMLTV, add this diagnostic:
export function diagnoseEpgMatching(
  channels: XtreamChannel[], 
  epgData: ParsedEpgData
): void {
  const epgChannelIds = new Set(Object.keys(epgData.programs));
  let matched = 0;
  let unmatched: string[] = [];
  
  channels.forEach(ch => {
    const epgId = ch.epg_channel_id || String(ch.stream_id);
    if (epgChannelIds.has(epgId)) {
      matched++;
    } else {
      unmatched.push(`${ch.name} (epg_id: ${epgId})`);
    }
  });
  
  console.log(`[EPG] Matched: ${matched}/${channels.length} channels`);
  if (unmatched.length > 0) {
    console.log('[EPG] Unmatched channels (first 20):', unmatched.slice(0, 20));
  }
}
```

**Step 2 — Implement fuzzy EPG channel matching:**

```typescript
// In xmltvEpg.ts, add fuzzy matching for when exact ID match fails:
function normalizeChannelId(id: string): string {
  return id
    .toLowerCase()
    .replace(/\s+/g, '')
    .replace(/[^a-z0-9]/g, '')
    .replace(/hd$/, '')
    .replace(/4k$/, '');
}

function findEpgChannelId(
  channel: XtreamChannel, 
  epgChannelMap: Map<string, string>
): string | null {
  // 1. Exact match on epg_channel_id
  if (channel.epg_channel_id && epgChannelMap.has(channel.epg_channel_id)) {
    return channel.epg_channel_id;
  }
  
  // 2. Exact match on channel name
  if (epgChannelMap.has(channel.name)) return channel.name;
  
  // 3. Fuzzy normalized match
  const normalizedChannelName = normalizeChannelId(channel.name);
  for (const [epgId] of epgChannelMap) {
    if (normalizeChannelId(epgId) === normalizedChannelName) {
      return epgId;
    }
  }
  
  // 4. Contains match (e.g., "ESPN" matches "ESPN HD")
  for (const [epgId] of epgChannelMap) {
    const normalizedEpgId = normalizeChannelId(epgId);
    if (normalizedEpgId.includes(normalizedChannelName) || 
        normalizedChannelName.includes(normalizedEpgId)) {
      return epgId;
    }
  }
  
  return null;
}
```

```typescript
async function parseXmltvWithWorker(xmlText: string): Promise<ParsedEpgData> {
  return new Promise((resolve, reject) => {
    const worker = new Worker(
      new URL('../workers/epgParser.worker.ts', import.meta.url),
      { type: 'module' }
    );
    
    const timeout = setTimeout(() => {
      worker.terminate();
      reject(new Error('EPG worker timed out after 30s'));
    }, 30000);
    
    worker.onmessage = (e) => {
      clearTimeout(timeout);
      worker.terminate();
      resolve(e.data);
    };
    
    worker.onerror = (e) => {
      clearTimeout(timeout);
      worker.terminate();
      // Fallback to main thread parsing if worker fails
      console.warn('[EPG] Worker failed, falling back to main thread parse');
      resolve(parseXmltvMainThread(xmlText));
    };
    
    worker.postMessage({ xmlText });
  });
}
```

```typescript
// In App.tsx, replace your EPG load block with a chunked loader:
async function loadEpgInBackground(channels: XtreamChannel[]) {
  setEpgStatus('loading');
  
  try {
    const cached = await loadEpgFromCache();
    if (cached && !isCacheStale(cached.timestamp, settings.epgRefreshHours)) {
      setEpgData(cached.data);
      setEpgStatus('ready');
      return;
    }
    
    // Load EPG sources in parallel but apply to state in chunks
    const sources = settings.epgSources || [];
    const results = await Promise.allSettled(
      sources.map(src => fetchAndParseEpgSource(src))
    );
    
    const merged: ParsedEpgData = { programs: {}, channels: {} };
    results.forEach(result => {
      if (result.status === 'fulfilled') {
        Object.assign(merged.programs, result.value.programs);
        Object.assign(merged.channels, result.value.channels);
      }
    });
    
    // Apply to state in a non-blocking way
    await new Promise(resolve => setTimeout(resolve, 0)); // yield to React
    setEpgData(merged);
    setEpgStatus('ready');
    
    // Cache in background — don't await this
    saveEpgToCache(merged).catch(console.error);
    
  } catch (err) {
    console.error('[EPG] Load failed:', err);
    setEpgStatus('error');
  }
}
```

```javascript
// In main.cjs DVR section:

const MAX_CONCURRENT_RECORDINGS = 3;
const activeRecordings = new Map(); // key: channelId, value: { process, startTime, outputPath }

ipcMain.handle('dvr:start', async (event, { channelId, channelName, streamUrl, outputDir }) => {
  if (activeRecordings.size >= MAX_CONCURRENT_RECORDINGS) {
    return { 
      success: false, 
      error: `Maximum ${MAX_CONCURRENT_RECORDINGS} simultaneous recordings reached` 
    };
  }
  
  if (activeRecordings.has(channelId)) {
    return { success: false, error: 'Already recording this channel' };
  }
  
  const ffmpegPath = getFFmpegPath();
  const timestamp = new Date().toISOString().replace(/[:.]/g, '-');
  const safeChannelName = channelName.replace(/[^a-zA-Z0-9\s]/g, '').trim().replace(/\s+/g, '_');
  const outputFile = path.join(outputDir, `${safeChannelName}_${timestamp}.ts`);
  
  const args = [
    '-y',                          // overwrite
    '-i', streamUrl,               // input
    '-c', 'copy',                  // copy streams without re-encoding (FAST)
    '-f', 'mpegts',                // output format
    '-movflags', '+faststart',
    outputFile
  ];
  
  const proc = spawn(ffmpegPath, args, { 
    stdio: ['pipe', 'pipe', 'pipe'],
    detached: false
  });
  
  activeRecordings.set(channelId, {
    process: proc,
    channelId,
    channelName,
    startTime: Date.now(),
    outputPath: outputFile,
    pid: proc.pid
  });
  
  proc.on('exit', (code) => {
    activeRecordings.delete(channelId);
    // Notify renderer:
    BrowserWindow.getAllWindows().forEach(w => 
      w.webContents.send('dvr:recording-ended', { channelId, code, outputPath: outputFile })
    );
  });
  
  proc.stderr.on('data', (data) => {
    // Parse FFmpeg progress from stderr:
    const progressMatch = data.toString().match(/time=(\d{2}:\d{2}:\d{2})/);
    if (progressMatch) {
      BrowserWindow.getAllWindows().forEach(w =>
        w.webContents.send('dvr:progress', { channelId, time: progressMatch[1] })
      );
    }
  });
  
  console.log(`[DVR] Started recording: ${channelName} → ${outputFile} (PID: ${proc.pid})`);
  return { success: true, outputPath: outputFile, pid: proc.pid };
});

ipcMain.handle('dvr:list-active', async () => {
  return Array.from(activeRecordings.values()).map(r => ({
    channelId: r.channelId,
    channelName: r.channelName,
    startTime: r.startTime,
    outputPath: r.outputPath,
    duration: Math.floor((Date.now() - r.startTime) / 1000)
  }));
});

ipcMain.handle('dvr:slots', async () => ({
  used: activeRecordings.size,
  max: MAX_CONCURRENT_RECORDINGS,
  available: MAX_CONCURRENT_RECORDINGS - activeRecordings.size
}));
```

```typescript
export function useTheme() {
  const { settings } = useSettings();

    const theme = themes[settings.theme as ThemeId] ?? themes.cyberpunk;

    root.style.setProperty('--text-primary', theme.textPrimary);
    root.style.setProperty('--text-secondary', theme.textSecondary);
    root.style.setProperty('--text-muted', theme.textMuted);
    root.style.setProperty('--glow-primary', theme.glowPrimary);
    root.style.setProperty('--glow-secondary', theme.glowSecondary);
```

```typescript
export function CategoryManager({ 
  categories, 
  onUpdate 
}: { 
  categories: XtreamCategory[];
  onUpdate: (configs: CategoryConfig[]) => void;
}) {
  const [configs, setConfigs] = useState<CategoryConfig[]>(() =>
    loadCategoryConfigs(categories)
  );
  const [filter, setFilter] = useState('');
  
  const sensors = useSensors(
    useSensor(PointerSensor),
    useSensor(KeyboardSensor, { coordinateGetter: sortableKeyboardCoordinates })
  );
  
  const handleDragEnd = (event: DragEndEvent) => {
    const { active, over } = event;
    if (active.id !== over?.id) {
      setConfigs(items => {
        const oldIndex = items.findIndex(i => i.id === active.id);
        const newIndex = items.findIndex(i => i.id === over?.id);
        const reordered = arrayMove(items, oldIndex, newIndex);
        return reordered.map((item, idx) => ({ ...item, order: idx }));
      });
    }
  };
  
  const filteredConfigs = configs.filter(c =>
    (c.customName ?? c.originalName).toLowerCase().includes(filter.toLowerCase())
  );
  
  return (
    <div className="space-y-4">
      {/* Filter + bulk actions */}
      <div className="flex items-center gap-3">
        <input
          value={filter}
          onChange={e => setFilter(e.target.value)}
          placeholder="Filter categories..."
          className="flex-1 bg-[var(--bg-tertiary)] border border-[var(--border-color)]
                     rounded-xl px-3 py-2 text-sm focus:outline-none 
                     focus:border-[var(--accent-primary)] transition-colors"
        />
```

```typescript
// src/services/customLists.ts
export interface CustomList {
  id: string;
  name: string;
  icon: string;          // emoji
  color: string;         // accent color
  type: 'live' | 'vod' | 'mixed';
  streamIds: number[];
  createdAt: number;
  updatedAt: number;
}

export const customListsService = {
  getLists(): CustomList[] {
    const raw = localStorage.getItem('custom-lists');
    return raw ? JSON.parse(raw) : [];
  },
  
  createList(name: string, icon = '📺', color = '#00d4ff', type: CustomList['type'] = 'mixed'): CustomList {
    const list: CustomList = {
      id: `list-${Date.now()}-${Math.random().toString(36).slice(2)}`,
      name,
      icon,
      color,
      type,
      streamIds: [],
      createdAt: Date.now(),
      updatedAt: Date.now(),
    };
    const lists = this.getLists();
    lists.push(list);
    localStorage.setItem('custom-lists', JSON.stringify(lists));
    return list;
  },
  
  addToList(listId: string, streamId: number): void {
    const lists = this.getLists();
    const list = lists.find(l => l.id === listId);
    if (!list) return;
    if (!list.streamIds.includes(streamId)) {
      list.streamIds.push(streamId);
      list.updatedAt = Date.now();
      localStorage.setItem('custom-lists', JSON.stringify(lists));
    }
  },
  
  removeFromList(listId: string, streamId: number): void {
    const lists = this.getLists();
    const list = lists.find(l => l.id === listId);
    if (!list) return;
    list.streamIds = list.streamIds.filter(id => id !== streamId);
    list.updatedAt = Date.now();
    localStorage.setItem('custom-lists', JSON.stringify(lists));
  },
  
  deleteList(listId: string): void {
    const lists = this.getLists().filter(l => l.id !== listId);
    localStorage.setItem('custom-lists', JSON.stringify(lists));
  },
  
  renameList(listId: string, name: string): void {
    const lists = this.getLists();
    const list = lists.find(l => l.id === listId);
    if (!list) return;
    list.name = name;
    list.updatedAt = Date.now();
    localStorage.setItem('custom-lists', JSON.stringify(lists));
  },
  
  reorderLists(orderedIds: string[]): void {
    const lists = this.getLists();
    const reordered = orderedIds
      .map(id => lists.find(l => l.id === id))
      .filter(Boolean) as CustomList[];
    localStorage.setItem('custom-lists', JSON.stringify(reordered));
  },
};
```

```typescript
// src/components/MiniPlayer.tsx
// A PiP-style mini player that floats in corner while you browse other pages

export function MiniPlayer({ stream, onExpand, onClose }: MiniPlayerProps) {
  const [pos, setPos] = useState({ x: window.innerWidth - 340, y: window.innerHeight - 220 });
  const [isDragging, setIsDragging] = useState(false);
  const dragStart = useRef<{ x: number; y: number; posX: number; posY: number }>();
  
  const handleMouseDown = (e: React.MouseEvent) => {
    setIsDragging(true);
    dragStart.current = { x: e.clientX, y: e.clientY, posX: pos.x, posY: pos.y };
  };
  
  const handleMouseMove = useCallback((e: MouseEvent) => {
    if (!isDragging || !dragStart.current) return;
    setPos({
      x: dragStart.current.posX + (e.clientX - dragStart.current.x),
      y: dragStart.current.posY + (e.clientY - dragStart.current.y),
    });
  }, [isDragging]);
  
  useEffect(() => {
    if (isDragging) {
      window.addEventListener('mousemove', handleMouseMove);
      window.addEventListener('mouseup', () => setIsDragging(false));
    }
    return () => {
      window.removeEventListener('mousemove', handleMouseMove);
    };
  }, [isDragging]);
  
  return (
    <motion.div
      initial={{ scale: 0, opacity: 0 }}
      animate={{ scale: 1, opacity: 1 }}
      exit={{ scale: 0, opacity: 0 }}
      style={{ left: pos.x, top: pos.y }}
      className="fixed z-[9998] w-80 h-48 rounded-2xl overflow-hidden
                 border border-[var(--border-color)] shadow-2xl cursor-move
                 group"
      onMouseDown={handleMouseDown}
    >
      {/* The MPV window is behind this — it'll need its position synced */}
      <div className="absolute inset-0 bg-black" />
      
      {/* Hover controls */}
      <div className="absolute inset-0 bg-black/50 opacity-0 group-hover:opacity-100
```

```typescript
// src/hooks/useKeyboardShortcuts.ts
export function useKeyboardShortcuts(mpv: UseMpvReturn, isPlayerActive: boolean) {
  
  useEffect(() => {
    if (!isPlayerActive) return;
    
    const handler = (e: KeyboardEvent) => {
      // Don't fire if user is typing in an input:
      if (e.target instanceof HTMLInputElement || e.target instanceof HTMLTextAreaElement) return;
      
      const shortcuts: Record<string, () => void> = {
        ' ':           mpv.togglePlayPause,
        'k':           mpv.togglePlayPause,
        'ArrowLeft':   () => mpv.seekRelative(-5),
        'ArrowRight':  () => mpv.seekRelative(5),
        'j':           () => mpv.seekRelative(-10),
        'l':           () => mpv.seekRelative(10),
        'ArrowUp':     () => mpv.setVolume(Math.min(100, (mpv.state.volume ?? 80) + 5)),
        'ArrowDown':   () => mpv.setVolume(Math.max(0, (mpv.state.volume ?? 80) - 5)),
        'm':           () => mpv.setMute(!mpv.state.muted),
        'f':           () => mpv.setFullscreen(!mpv.state.fullscreen),
        's':           mpv.takeScreenshot,
        'c':           () => toggleCaptions(),   // cycle subtitle tracks
        'a':           () => cycleAudioTrack(),  // cycle audio tracks
        '[':           () => mpv.setAudioDelay((mpv.state.audioDelay ?? 0) - 0.1),
        ']':           () => mpv.setAudioDelay((mpv.state.audioDelay ?? 0) + 0.1),
        'Escape':      () => exitPlayer(),
        '?':           () => setShowShortcutHelp(true),
      };
      
      const action = shortcuts[e.key];
      if (action) {
        e.preventDefault();
        action();
      }
    };
    
    window.addEventListener('keydown', handler);
    return () => window.removeEventListener('keydown', handler);
  }, [mpv, isPlayerActive]);
}
```

## Top 5 Vibe Coding Tricks for This Stack

1. **Never fight Tailwind + CSS vars** — Define all your neon theme colors as CSS custom properties (as shown above), then reference them in Tailwind via the `extend` config. This gives you hot-reload-safe theming with zero runtime JS overhead.

2. **MPV is a black box — log everything** — Add timestamps to every MPV IPC message in development. The race between "MPV spawned" and "MPV IPC pipe ready" is your #1 source of mysterious live TV failures. A readiness gate (Section 1.1 Culprit D) eliminates an entire class of bugs.

3. **Virtualize everything** — Your `VirtualContentGrid.tsx` is already there. Make sure every list over 50 items goes through it. Channel lists of 10,000+ items will freeze React without virtualization. Use `react-window` or `@tanstack/react-virtual` for both grids and EPG guide timelines.

4. **Background sync pattern** — For EPG, TMDB, and category loading, always: (a) show cached data immediately, (b) kick off a background refresh, (c) merge new data into state without a loading spinner. This makes the app feel instantaneous even on slow providers.

5. **The MPV backing window trick is your superpower** — None of your competitors have native MPV embedded in a beautiful React UI. Lean into this. The stats overlay, subtitle style editor, screenshot with neon flash effect — all of these are things that are simply impossible with a `<video>` tag. Make them prominent in your UI so users know immediately this is a different class of player.
