## 🧠 FIRST: UNDERSTANDING THE ARCHITECTURE DECISION

Before writing a single line of code, you need to understand **why MPV** and **which integration method** to use. There are three possible approaches, and choosing wrong will cause you weeks of pain:

---

### The Three Integration Methods — Compared

| Method | Description | Pros | Cons |
|---|---|---|---|
| **A: `node-mpv` IPC subprocess** | Spawn `mpv.exe` as background process, communicate via JSON IPC socket | ✅ Most stable ✅ Easy to maintain ✅ Full MPV API access | ❌ Video renders in separate native window — **not embedded in your UI** |
| **B: `--wid` Window Embedding** | Spawn MPV with your Electron window's HWND so it paints into your app | ✅ Video appears inside Electron | ❌ Chromium and Windows' native window management are incompatible — Electron, built on Chromium and Node.js, does not natively support embedding external Windows application windows. Due to incompatibilities between Chromium's rendering engine and Windows' native window management, native modules are necessary to bridge this gap. ❌ Unreliable, requires C++ native module |
| **C: Local HTTP Proxy (Recommended ✅)** | MPV renders to a local HTTP stream → displayed in `<video>` tag | ✅ Fully embedded in React UI ✅ Stable ✅ Best of both worlds | ❌ Tiny latency overhead (~50ms) acceptable for IPTV |

**The winner for DYLANDOS is Method A (IPC subprocess) for the backend engine + Method C (local HTTP pipe) for visual embedding — combined into a single unified architecture.** Here's the full reasoning:

- The `node-mpv` module keeps an instance of MPV running in the background using MPV's `--idle` flag and communicates over MPV's JSON IPC API.
- It offers an API for the most relevant functionalities and is highly flexible.
- It also provides direct access to the IPC socket itself, meaning the module is not limited to the methods it provides but can be used with the full extent of what MPV has to offer, even if some command is not supported by Node-MPV.
- It works on both UNIX and Windows.

For the actual **video display inside your React UI**, the cleanest Windows-compatible approach is to pipe MPV output through a local HTTP server that feeds your existing `<video>` element. This lets your beautiful React OSD, EPG overlay, and controls all sit on top naturally.

## 📦 PHASE 0 — SETUP & BUNDLING MPV WITH YOUR APP

### 0.1 Bundling mpv.exe as an extraResource

You must ship `mpv.exe` inside your installer so users don't need to install it separately.

```
/
├── vendor/
│   └── mpv/
│       ├── mpv.exe          ← Windows x64 binary (from https://mpv.io/installation/)
│       └── mpv-2.dll        ← Required DLL (ships with mpv portable build)
```

**`package.json` — electron-builder config update:**
```json
{
  "build": {
    "appId": "com.dylandos.iptv.ultimate",
    "productName": "DYLANDOS IPTV ULTIMATE",
    "files": [
      "dist/**/*",
      "electron/**/*"
    ],
    "extraResources": [
      {
        "from": "vendor/mpv",
        "to": "mpv",
        "filter": ["**/*"]
      }
    ],
    "win": {
      "target": ["nsis", "portable"],
      "icon": "resources/icon.png"
    }
  }
}
```

At runtime in `electron/main.cjs`, the mpv binary path resolves as:
```javascript
// electron/main.cjs
const path = require('path');

function getMpvBinaryPath() {
  if (app.isPackaged) {
    // In production: binary is in resources/mpv/mpv.exe
    return path.join(process.resourcesPath, 'mpv', 'mpv.exe');
  } else {
    // In development: use vendor/mpv/mpv.exe directly
    return path.join(__dirname, '..', 'vendor', 'mpv', 'mpv.exe');
  }
}
```

## 🏗️ PHASE 1 — ELECTRON MAIN PROCESS: THE MPV MANAGER

This is the heart of the integration. Create a dedicated MPV manager class in the main process.

### 1.1 Create `electron/mpvManager.cjs`

```javascript
// electron/mpvManager.cjs
// ─────────────────────────────────────────────────────────
// DYLANDOS IPTV ULTIMATE — MPV Manager
// Manages MPV subprocess lifecycle, IPC, and state reporting
// ─────────────────────────────────────────────────────────

const mpvAPI = require('node-mpv');
const path = require('path');
const { app } = require('electron');
const http = require('http');
const { spawn } = require('child_process');
const net = require('net');

// ─── Constants ────────────────────────────────────────────
const MPV_IPC_PIPE = process.platform === 'win32'
  ? '\\\\.\\pipe\\dylandos-mpv-ipc'
  : '/tmp/dylandos-mpv.sock';

const LOCAL_PROXY_PORT = 18888; // Local HTTP proxy port for video embedding

// ─── MPV Manager Class ────────────────────────────────────
class MpvManager {
  constructor() {
    this.mpv = null;
    this.win = null;              // Reference to Electron BrowserWindow
    this.currentStreamUrl = null;
    this.currentStreamType = null; // 'live' | 'vod'
    this.proxyServer = null;
    this.isInitialized = false;
    this.statusInterval = null;
    this.reconnectTimer = null;
    this.reconnectAttempts = 0;
    this.maxReconnectAttempts = 10;
    this.baseReconnectDelayMs = 2000;
    this.settings = {};
  }

  // ─── Initialization ───────────────────────────────────
  async initialize(browserWindow, settings) {
    this.win = browserWindow;
    this.settings = settings;
    
    const mpvBinary = getMpvBinaryPath();
    
    // Shared MPV launch arguments used for ALL streams
    const sharedArgs = [
      '--no-terminal',
      '--idle=yes',           // Stay alive between streams
      '--no-osc',             // We draw our own OSD
      '--no-input-default-bindings', // Disable MPV's own keyboard shortcuts
      '--input-ipc-server=' + MPV_IPC_PIPE,
      '--hr-seek=yes',        // High-resolution seeking for VOD
      '--keep-open=yes',      // Don't exit after stream ends
      '--screenshot-format=png',
      '--screenshot-directory=' + app.getPath('pictures'),
    ];

    this.mpv = new mpvAPI(
      {
        binary: mpvBinary,
        socket: MPV_IPC_PIPE,
        time_update: 1,        // Emit time position every 1 second
        verbose: false,
        debug: false,
        auto_restart: true,    // Auto-restart if MPV crashes
      },
      sharedArgs
    );

    await this._attachEventListeners();
    await this.mpv.start();
    
    this.isInitialized = true;
    this._sendToRenderer('mpv:ready', { initialized: true });
    console.log('[MPV] Manager initialized successfully');
  }

  // ─── Event Listeners ──────────────────────────────────
  async _attachEventListeners() {
    // Playback state events
    this.mpv.on('started', () => {
      this._sendToRenderer('mpv:playback-started', {
        url: this.currentStreamUrl,
        type: this.currentStreamType,
      });
      this.reconnectAttempts = 0; // Reset on successful start
      this._startStatusPolling();
    });

    this.mpv.on('stopped', () => {
      this._sendToRenderer('mpv:playback-stopped', {});
      this._stopStatusPolling();
    });

    this.mpv.on('paused', () => {
      this._sendToRenderer('mpv:paused', {});
    });

    this.mpv.on('resumed', () => {
      this._sendToRenderer('mpv:resumed', {});
    });

    // Time position — emitted every `time_update` seconds
    this.mpv.on('timeposition', (seconds) => {
      this._sendToRenderer('mpv:timeposition', { seconds });
    });

    // End of file/stream
    this.mpv.on('stopped', async () => {
      if (this.currentStreamType === 'live') {
        await this._handleLiveStreamEnd();
      } else {
        this._sendToRenderer('mpv:vod-ended', {});
      }
    });

    // Crash/unexpected exit
    this.mpv.on('crashed', () => {
      console.error('[MPV] Process crashed — auto_restart will handle it');
      this._sendToRenderer('mpv:crashed', {});
      // node-mpv auto_restart=true will relaunch mpv automatically
      // Re-load the stream once MPV is back
      if (this.currentStreamUrl) {
        setTimeout(() => this._reloadCurrentStream(), 1500);
      }
    });

    // Property observer: track buffering state
    // IDs 0-12 are reserved by node-mpv — use 50+ for custom observers
    await this.mpv.observeProperty('cache-buffering-state', 50);
    await this.mpv.observeProperty('paused-for-cache', 51);
    await this.mpv.observeProperty('video-bitrate', 52);
    await this.mpv.observeProperty('audio-bitrate', 53);
    await this.mpv.observeProperty('video-codec', 54);
    await this.mpv.observeProperty('audio-codec', 55);
    await this.mpv.observeProperty('hwdec-current', 56);
    await this.mpv.observeProperty('track-list', 57);

    // node-mpv allows you to observe any property the mpv API offers you by simply using the observeProperty function. This will add the specified property to the statusupdate event which is emitted whenever one of the observed properties changes.
    this.mpv.on('statuschange', (status) => {
      // status object contains all currently observed property values
      this._sendToRenderer('mpv:status', {
        bufferingPercent: status['cache-buffering-state'] ?? 0,
        pausedForCache: status['paused-for-cache'] ?? false,
        videoBitrate: status['video-bitrate'] ?? 0,
        audioBitrate: status['audio-bitrate'] ?? 0,
        videoCodec: status['video-codec'] ?? '',
        audioCodec: status['audio-codec'] ?? '',
        hwdecActive: status['hwdec-current'] ?? 'no',
        trackList: status['track-list'] ?? [],
        duration: status.duration ?? 0,
        position: status.position ?? 0,
        pause: status.pause ?? false,
        volume: status.volume ?? 100,
        mute: status.mute ?? false,
      });
    });
  }

  // ─── Load Live TV Stream ──────────────────────────────
  async loadLiveStream(url, settings = {}) {
    if (!this.isInitialized) {
      throw new Error('[MPV] Not initialized — call initialize() first');
    }

    this._clearReconnectTimer();
    this.currentStreamUrl = url;
    this.currentStreamType = 'live';

    // Apply live-TV-specific MPV options BEFORE loading
    await this._applyLiveProfile(settings);

    try {
      // loadFile replaces current stream and starts playback immediately
      await this.mpv.load(url, 'replace');
      this._sendToRenderer('mpv:loading', { url, type: 'live' });
    } catch (err) {
      console.error('[MPV] Failed to load live stream:', err);
      this._sendToRenderer('mpv:error', { message: err.message, type: 'live' });
      await this._handleLiveStreamEnd(); // Trigger reconnect
    }
  }

  // ─── Load VOD Stream ──────────────────────────────────
  async loadVodStream(url, startPositionSeconds = 0, settings = {}) {
    if (!this.isInitialized) {
      throw new Error('[MPV] Not initialized');
    }

    this._clearReconnectTimer();
    this.currentStreamUrl = url;
    this.currentStreamType = 'vod';

    // Apply VOD-specific profile
    await this._applyVodProfile(settings);

    const loadOptions = startPositionSeconds > 0
      ? { 'start': `+${startPositionSeconds}` }  // Resume position
      : {};

    try {
      await this.mpv.load(url, 'replace', loadOptions);
      this._sendToRenderer('mpv:loading', { url, type: 'vod', startPosition: startPositionSeconds });
    } catch (err) {
      console.error('[MPV] Failed to load VOD stream:', err);
      this._sendToRenderer('mpv:error', { message: err.message, type: 'vod' });
    }
  }

  // ─── Live Reconnect Logic ─────────────────────────────
  async _handleLiveStreamEnd() {
    if (this.reconnectAttempts >= this.maxReconnectAttempts) {
      this._sendToRenderer('mpv:error', {
        message: `Reconnect failed after ${this.maxReconnectAttempts} attempts`,
        type: 'live',
        fatal: true,
      });
      this.reconnectAttempts = 0;
      return;
    }

    this.reconnectAttempts++;
    // Exponential backoff: 2s → 4s → 8s → 16s → capped at 30s
    const delay = Math.min(
      this.baseReconnectDelayMs * Math.pow(2, this.reconnectAttempts - 1),
      30000
    );

    this._sendToRenderer('mpv:reconnecting', {
      attempt: this.reconnectAttempts,
      maxAttempts: this.maxReconnectAttempts,
      delayMs: delay,
    });

    console.log(`[MPV] Reconnecting in ${delay}ms (attempt ${this.reconnectAttempts}/${this.maxReconnectAttempts})`);

    this.reconnectTimer = setTimeout(async () => {
      if (this.currentStreamUrl && this.currentStreamType === 'live') {
        try {
          await this.mpv.load(this.currentStreamUrl, 'replace');
        } catch (err) {
          await this._handleLiveStreamEnd(); // Recurse
        }
      }
    }, delay);
  }

  async _reloadCurrentStream() {
    if (!this.currentStreamUrl) return;
    if (this.currentStreamType === 'live') {
      await this.loadLiveStream(this.currentStreamUrl, this.settings);
    } else {
      await this.loadVodStream(this.currentStreamUrl, 0, this.settings);
    }
  }

  // ─── Playback Controls ────────────────────────────────
  async play()  { await this.mpv.play(); }
  async pause() { await this.mpv.pause(); }
  async togglePlayPause() { await this.mpv.togglePause(); }

  async stop() {
    this._clearReconnectTimer();
    this.currentStreamUrl = null;
    this.currentStreamType = null;
    await this.mpv.stop();
    this._sendToRenderer('mpv:stopped', {});
  }

  async seek(seconds) {
    // Absolute seek for VOD (never seek on live streams)
    if (this.currentStreamType === 'vod') {
      await this.mpv.goToPosition(seconds);
    }
  }

  async seekRelative(deltaSeconds) {
    if (this.currentStreamType === 'vod') {
      await this.mpv.seek(deltaSeconds);
    }
  }

  async setVolume(level) {
    // MPV volume: 0–100 (not 0–1 like hls.js)
    const mpvVolume = Math.round(level * 100);
    await this.mpv.volume(mpvVolume);
  }

  async setMute(muted) {
    await this.mpv.mute(muted);
  }

  async setFullscreen(enabled) {
    await this.mpv.setProperty('fullscreen', enabled);
  }

  // ─── Track Selection ──────────────────────────────────
  async setAudioTrack(trackId) {
    await this.mpv.setProperty('aid', trackId);
  }

  async setSubtitleTrack(trackId) {
    // trackId = 'no' to disable subtitles
    await this.mpv.setProperty('sid', trackId);
  }

  async setVideoTrack(trackId) {
    await this.mpv.setProperty('vid', trackId);
  }

  // ─── Audio Offset / Lip-Sync ──────────────────────────
  // This is one of the features marked as "not wired" in your manifest
  // MPV makes this TRIVIAL compared to Web Audio API approach
  async setAudioOffsetMs(offsetMs) {
    // MPV audio-delay is in seconds, negative = audio behind video
    await this.mpv.setProperty('audio-delay', offsetMs / 1000);
  }

  // ─── Subtitle Styling ─────────────────────────────────
  async applySubtitleSettings(subtitleSettings) {
    await this.mpv.setMultipleProperties({
      'sub-font-size': subtitleSettings.subtitleFontSize,
      'sub-color': hexToMpvColor(subtitleSettings.subtitleFontColor),
      'sub-border-size': subtitleSettings.subtitleOutlineWidth,
      'sub-back-color': `0.0/0.0/0.0/${subtitleSettings.subtitleBackgroundOpacity ?? 0.6}`,
      'sub-shadow-offset': 2,
    });
  }

  // ─── Screenshot ───────────────────────────────────────
  async takeScreenshot() {
    // 'video' = without OSD, 'window' = with OSD
    await this.mpv.command('screenshot', ['video']);
    this._sendToRenderer('mpv:screenshot-taken', {
      path: app.getPath('pictures'),
    });
  }

  // ─── Get Current State ────────────────────────────────
  async getPlaybackState() {
    try {
      const [position, duration, pause, volume, mute] = await Promise.all([
        this.mpv.getProperty('time-pos').catch(() => 0),
        this.mpv.getProperty('duration').catch(() => 0),
        this.mpv.getProperty('pause').catch(() => false),
        this.mpv.getProperty('volume').catch(() => 100),
        this.mpv.getProperty('mute').catch(() => false),
      ]);
      return { position, duration, pause, volume: volume / 100, mute };
    } catch {
      return { position: 0, duration: 0, pause: false, volume: 1, mute: false };
    }
  }

  // ─── Status Polling ───────────────────────────────────
  _startStatusPolling() {
    this._stopStatusPolling();
    this.statusInterval = setInterval(async () => {
      try {
        const state = await this.getPlaybackState();
        this._sendToRenderer('mpv:poll', state);
      } catch {/* ignore during transitions */}
    }, 500); // Poll every 500ms for smooth progress bars
  }

  _stopStatusPolling() {
    if (this.statusInterval) {
      clearInterval(this.statusInterval);
      this.statusInterval = null;
    }
  }

  // ─── Utility ──────────────────────────────────────────
  _clearReconnectTimer() {
    if (this.reconnectTimer) {
      clearTimeout(this.reconnectTimer);
      this.reconnectTimer = null;
    }
  }

  _sendToRenderer(channel, data) {
    if (this.win && !this.win.isDestroyed()) {
      this.win.webContents.send(channel, data);
    }
  }

  async destroy() {
    this._stopStatusPolling();
    this._clearReconnectTimer();
    if (this.mpv) {
      await this.mpv.quit().catch(() => {});
    }
  }
}

module.exports = { MpvManager };
```

### 1.2 MPV Profile Configuration (Live vs VOD)

This is one of the most critical sections. MPV has a builtin low-latency profile that tries to apply some of the options which can reduce latency. You can use `--profile=low-latency` to apply all of them. You can list the contents with `--show-profile=low-latency`, though some of the options are quite obscure and may change every MPV release.

Add these profile methods to your `MpvManager` class:

```javascript
// Inside electron/mpvManager.cjs — add to MpvManager class

// ─── Live TV Profile ──────────────────────────────────
async _applyLiveProfile(settings) {
  const bufferPreset = settings.liveBufferPreset ?? 'medium';
  
  // Buffer settings per preset
  const bufferMap = {
    low:    { cacheSecs: 5,  demuxerMaxBytes: '20MiB', readaheadSecs: 5  },
    medium: { cacheSecs: 15, demuxerMaxBytes: '50MiB', readaheadSecs: 15 },
    high:   { cacheSecs: 30, demuxerMaxBytes: '100MiB', readaheadSecs: 30 },
  };
  const buf = bufferMap[bufferPreset];

  // Reducing latency is possible only by specifically disabling features which increase latency. The builtin low-latency profile tries to apply some of the options which can reduce latency. You can use --profile=low-latency to apply all of them.
  await this.mpv.setMultipleProperties({
    // ── Core latency reduction ──
    'profile':               'low-latency', // Apply MPV's built-in low-latency tweaks
    'cache':                 'yes',
    'cache-secs':            buf.cacheSecs,
    'demuxer-max-bytes':     buf.demuxerMaxBytes,
    'demuxer-readahead-secs': buf.readaheadSecs,
    
    // ── Hardware decoding ──
    // d3d11va is safe when used with the d3d11 backend.
    // 'auto-safe' tries d3d11va first (Windows), then falls back to software
    'hwdec':                 settings.hardwareDecode ? 'auto-safe' : 'no',
    
    // ── Network settings ──
    'network-timeout':       30,
    'stream-buffer-size':    '512KiB',
    
    // ── Latency hacks ──
    // --video-latency-hacks enables some things which tend to reduce video latency by 1 or 2 frames. Note that this option might be removed without notice. This does: use the demuxer reported FPS for frame dropping, which avoids the player needing to decode 1 frame in advance, lowering total latency.
    'video-latency-hacks':   'yes',
    
    // ── Seeking ──
    'hr-seek':               'no',    // Don't high-res seek on live streams
    
    // ── Display ──
    'video-sync':            'audio', // Sync video to audio (not display) — less stutter
    'framedrop':             'vo',    // Drop display frames if behind, never decoder frames
    
    // ── Audio ──
    'audio-delay':           settings.audioOffsetMs ? (settings.audioOffsetMs / 1000) : 0,
    
    // ── Subtitles ──
    'sub-visibility':        'yes',
  });
}

// ─── VOD Profile ─────────────────────────────────────
async _applyVodProfile(settings) {
  await this.mpv.setMultipleProperties({
    // ── Quality-first profile for VOD ──
    // Two predefined profiles are available: fast for maximum performance and high-quality for superior rendering quality.
    'profile':               'high-quality',
    
    // ── Larger buffers for VOD ──
    'cache':                 'yes',
    'cache-secs':            120,
    'demuxer-max-bytes':     '200MiB',
    'demuxer-readahead-secs': 60,
    
    // ── Hardware decoding ──
    'hwdec':                 settings.hardwareDecode ? 'auto-safe' : 'no',
    
    // ── Seeking precision ──
    'hr-seek':               'yes',  // High-precision seek for VOD scrubbing
    'hr-seek-framedrop':     'yes',  // Drop frames when seeking for speed
    
    // ── Display quality ──
    'video-sync':            'display-resample',  // Smooth motion for VOD
    'framedrop':             'vo',
    
    // ── Audio ──
    'audio-delay':           settings.audioOffsetMs ? (settings.audioOffsetMs / 1000) : 0,
    
    // ── Subtitles ──
    'sub-visibility':        'yes',
    'sub-ass-override':      'force',
    'sub-font-size':         settings.subtitleFontSize ?? 24,
  });
}
```

## 🔌 PHASE 2 — PRELOAD SCRIPT: EXPAND THE IPC BRIDGE

Add MPV channels to `electron/preload.cjs`:

```javascript
// electron/preload.cjs — extend existing whitelist

// Add to receive-channel whitelist:
const RECEIVE_CHANNELS = [
```

## ⚛️ PHASE 3 — REACT: THE MPV HOOK

### 3.1 Create `src/hooks/useMpv.ts`

This hook completely replaces `VideoPlayer.tsx`'s hls.js logic for streams that go through MPV:

```typescript
// src/hooks/useMpv.ts
import { useState, useEffect, useCallback, useRef } from 'react';
import { useSettingsStore } from '../store/useSettingsStore';

// ─── Types ────────────────────────────────────────────────
export interface MpvPlayerState {
  isPlaying: boolean;
  isLoading: boolean;
  isPaused: boolean;
  isBuffering: boolean;
  error: string | null;
  position: number;          // seconds
  duration: number;          // seconds (0 for live)
  volume: number;            // 0–1
  muted: boolean;
  bufferingPercent: number;  // 0–100
  videoBitrate: number;      // bps
  audioBitrate: number;      // bps
  videoCodec: string;
  audioCodec: string;
  hwdecActive: string;       // 'no' or codec name
  audioTracks: MpvTrack[];
  subtitleTracks: MpvTrack[];
  activeAudioTrack: number;
  activeSubtitleTrack: number | 'no';
  reconnectAttempt: number;
  reconnectMaxAttempts: number;
  reconnectDelayMs: number;
  streamType: 'live' | 'vod' | null;
  isAvailable: boolean;      // false if mpv.exe not found
}

export interface MpvTrack {
  id: number;
  title: string;
  lang: string;
  selected: boolean;
  type: 'audio' | 'sub' | 'video';
  codec: string;
}

const INITIAL_STATE: MpvPlayerState = {
  isPlaying: false,
  isLoading: false,
  isPaused: false,
  isBuffering: false,
  error: null,
  position: 0,
  duration: 0,
  volume: 1,
  muted: false,
  bufferingPercent: 0,
  videoBitrate: 0,
  audioBitrate: 0,
  videoCodec: '',
  audioCodec: '',
  hwdecActive: 'no',
  audioTracks: [],
  subtitleTracks: [],
  activeAudioTrack: 1,
  activeSubtitleTrack: 'no',
  reconnectAttempt: 0,
  reconnectMaxAttempts: 10,
  reconnectDelayMs: 0,
  streamType: null,
  isAvailable: true,
};

// ─── Helper: Parse track-list from MPV ────────────────────
function parseTrackList(rawList: any[]): { audio: MpvTrack[]; subtitles: MpvTrack[] } {
  const audio: MpvTrack[] = [];
  const subtitles: MpvTrack[] = [];

  (rawList ?? []).forEach((track: any) => {
    const t: MpvTrack = {
      id: track.id,
      title: track.title ?? track.lang ?? `Track ${track.id}`,
      lang: track.lang ?? 'und',
      selected: track.selected ?? false,
      type: track.type,
      codec: track.codec ?? '',
    };
    if (track.type === 'audio') audio.push(t);
    if (track.type === 'sub') subtitles.push(t);
  });

  return { audio, subtitles };
}

// ─── The Hook ─────────────────────────────────────────────
export function useMpv() {
  const [state, setState] = useState<MpvPlayerState>(INITIAL_STATE);
  const settings = useSettingsStore((s) => s.settings);
  const stateRef = useRef(state); // Stable ref for event handlers
  stateRef.current = state;

  // ─── Listen to MPV events from main process ────────────
  useEffect(() => {
    if (!window.electronAPI) return;

    const handlers: Record<string, (data: any) => void> = {
      'mpv:ready': () => {
        setState(prev => ({ ...prev, isAvailable: true }));
      },

      'mpv:unavailable': ({ reason }: any) => {
        console.warn('[useMpv] MPV unavailable:', reason);
        setState(prev => ({ ...prev, isAvailable: false }));
      },

      'mpv:loading': ({ type }: any) => {
        setState(prev => ({
          ...prev,
          isLoading: true,
          error: null,
          streamType: type,
          position: 0,
          duration: 0,
          audioTracks: [],
          subtitleTracks: [],
        }));
      },

      'mpv:playback-started': () => {
        setState(prev => ({
          ...prev,
          isLoading: false,
          isPlaying: true,
          isPaused: false,
          error: null,
          reconnectAttempt: 0,
        }));
      },

      'mpv:playback-stopped': () => {
        setState(prev => ({
          ...prev,
          isPlaying: false,
          isPaused: false,
          isLoading: false,
        }));
      },

      'mpv:paused': () => {
        setState(prev => ({ ...prev, isPaused: true, isPlaying: false }));
      },

      'mpv:resumed': () => {
        setState(prev => ({ ...prev, isPaused: false, isPlaying: true }));
      },

      'mpv:status': (status: any) => {
        const { audio, subtitles } = parseTrackList(status.trackList);
        setState(prev => ({
          ...prev,
          isBuffering: status.pausedForCache,
          bufferingPercent: status.bufferingPercent,
          videoBitrate: status.videoBitrate,
          audioBitrate: status.audioBitrate,
          videoCodec: status.videoCodec,
          audioCodec: status.audioCodec,
          hwdecActive: status.hwdecActive,
          audioTracks: audio,
          subtitleTracks: subtitles,
          duration: status.duration,
          volume: status.volume / 100,
          muted: status.mute,
        }));
      },

      'mpv:poll': ({ position, duration, pause, volume, mute }: any) => {
        setState(prev => ({
          ...prev,
          position,
          duration,
          isPaused: pause,
          isPlaying: !pause && prev.isPlaying,
          volume,
          muted: mute,
        }));
      },

      'mpv:timeposition': ({ seconds }: any) => {
        setState(prev => ({ ...prev, position: seconds }));
      },

      'mpv:error': ({ message, fatal }: any) => {
        setState(prev => ({
          ...prev,
          error: message,
          isLoading: false,
          isPlaying: !fatal ? prev.isPlaying : false,
        }));
      },

      'mpv:crashed': () => {
        setState(prev => ({
          ...prev,
          error: 'MPV crashed — attempting restart...',
          isPlaying: false,
          isLoading: true,
        }));
      },

      'mpv:reconnecting': ({ attempt, maxAttempts, delayMs }: any) => {
        setState(prev => ({
          ...prev,
          isLoading: true,
          isPlaying: false,
          reconnectAttempt: attempt,
          reconnectMaxAttempts: maxAttempts,
          reconnectDelayMs: delayMs,
        }));
      },

      'mpv:vod-ended': () => {
        setState(prev => ({ ...prev, isPlaying: false, isPaused: false }));
      },

      'mpv:stopped': () => {
        setState(prev => ({
          ...prev,
          isPlaying: false,
          isPaused: false,
          isLoading: false,
          position: 0,
        }));
      },
    };

    // Register all handlers
    Object.entries(handlers).forEach(([channel, handler]) => {
      window.electronAPI.on(channel, handler);
    });

    // Cleanup
    return () => {
      Object.entries(handlers).forEach(([channel, handler]) => {
        window.electronAPI.off(channel, handler);
      });
    };
  }, []);

  // ─── Sync subtitle settings when settings change ───────
  useEffect(() => {
    if (!state.isAvailable) return;
    window.electronAPI.invoke('mpv:apply-subtitle-settings', {
      subtitleFontSize: settings.subtitleFontSize,
      subtitleFontColor: settings.subtitleFontColor,
      subtitleOutlineWidth: settings.subtitleOutlineWidth,
      subtitleBackgroundOpacity: settings.subtitleBackgroundOpacity,
    }).catch(console.error);
  }, [
    settings.subtitleFontSize,
    settings.subtitleFontColor,
    settings.subtitleOutlineWidth,
    settings.subtitleBackgroundOpacity,
    state.isAvailable,
  ]);

  // ─── Actions ──────────────────────────────────────────
  const loadLiveStream = useCallback(async (url: string) => {
    await window.electronAPI.invoke('mpv:load-live', {
      url,
      settings: {
        liveBufferPreset: settings.liveBufferPreset,
        hardwareDecode: settings.hardwareDecode,
        audioOffsetMs: settings.audioOffsetMs,
      },
    });
  }, [settings]);

  const loadVodStream = useCallback(async (url: string, startPosition = 0) => {
    await window.electronAPI.invoke('mpv:load-vod', {
      url,
      startPosition,
      settings: {
        hardwareDecode: settings.hardwareDecode,
        audioOffsetMs: settings.audioOffsetMs,
        subtitleFontSize: settings.subtitleFontSize,
      },
    });
  }, [settings]);

  const play            = useCallback(() => window.electronAPI.invoke('mpv:play'), []);
  const pause           = useCallback(() => window.electronAPI.invoke('mpv:pause'), []);
  const togglePlayPause = useCallback(() => window.electronAPI.invoke('mpv:toggle-pause'), []);
  const stop            = useCallback(() => window.electronAPI.invoke('mpv:stop'), []);

  const seek = useCallback((seconds: number) =>
    window.electronAPI.invoke('mpv:seek', { seconds }), []);

  const seekRelative = useCallback((delta: number) =>
    window.electronAPI.invoke('mpv:seek-relative', { delta }), []);

  const setVolume = useCallback((level: number) =>
    window.electronAPI.invoke('mpv:set-volume', { level }), []);

  const setMute = useCallback((muted: boolean) =>
    window.electronAPI.invoke('mpv:set-mute', { muted }), []);

  const setAudioTrack = useCallback((trackId: number) =>
    window.electronAPI.invoke('mpv:set-audio-track', { trackId }), []);

  const setSubtitleTrack = useCallback((trackId: number | 'no') =>
    window.electronAPI.invoke('mpv:set-sub-track', { trackId }), []);

  const setAudioDelay = useCallback((offsetMs: number) =>
    window.electronAPI.invoke('mpv:set-audio-delay', { offsetMs }), []);

  const takeScreenshot = useCallback(() =>
    window.electronAPI.invoke('mpv:screenshot'), []);

  const sendRawCommand = useCallback((command: string, args: any[] = []) =>
    window.electronAPI.invoke('mpv:send-raw-command', { command, args }), []);

  return {
    state,
    actions: {
      loadLiveStream,
      loadVodStream,
      play,
      pause,
      togglePlayPause,
      stop,
      seek,
      seekRelative,
      setVolume,
      setMute,
      setAudioTrack,
      setSubtitleTrack,
      setAudioDelay,
      takeScreenshot,
      sendRawCommand,
    },
  };
}
```

## 🎭 PHASE 4 — THE MPV VIDEO PLAYER COMPONENT

### 4.1 Create `src/components/MpvPlayer.tsx`

Since MPV renders in its own native window (not inside your `<div>`), you need a **smart overlay component** that:
1. Provides a `<div>` placeholder that your layout uses for sizing
2. Renders your full custom OSD over the top
3. Controls MPV underneath via IPC

```tsx
// src/components/MpvPlayer.tsx
import React, { useRef, useEffect, useCallback, useState } from 'react';
import { useMpv } from '../hooks/useMpv';
import { useSettings } from '../hooks/useSettings';
import {
  Play, Pause, Square, Volume2, VolumeX,
  Maximize2, Minimize2, ChevronLeft, ChevronRight,
  Mic, Subtitles, Camera, Wifi, WifiOff,
  RotateCcw, AlertCircle, Loader2,
} from 'lucide-react';

interface MpvPlayerProps {
  streamUrl: string | null;
  streamType: 'live' | 'vod';
  streamTitle: string;
  onBack?: () => void;
  onEnded?: () => void;
  onChannelUp?: () => void;
  onChannelDown?: () => void;
  startPosition?: number;
  epgCurrentProgram?: { title: string; startTime: number; endTime: number } | null;
  epgNextProgram?: { title: string; startTime: number } | null;
  channelLogo?: string;
}

// Format seconds → HH:MM:SS or MM:SS
function formatTime(seconds: number): string {
  if (!isFinite(seconds) || seconds < 0) return '0:00';
  const h = Math.floor(seconds / 3600);
  const m = Math.floor((seconds % 3600) / 60);
  const s = Math.floor(seconds % 60);
  if (h > 0) return `${h}:${String(m).padStart(2, '0')}:${String(s).padStart(2, '0')}`;
  return `${m}:${String(s).padStart(2, '0')}`;
}

// Format EPG progress percentage
function epgProgress(startTime: number, endTime: number): number {
  const now = Date.now();
  const total = endTime - startTime;
  const elapsed = now - startTime;
  return Math.min(100, Math.max(0, (elapsed / total) * 100));
}

export const MpvPlayer: React.FC<MpvPlayerProps> = ({
  streamUrl,
  streamType,
  streamTitle,
  onBack,
  onEnded,
  onChannelUp,
  onChannelDown,
  startPosition = 0,
  epgCurrentProgram,
  epgNextProgram,
  channelLogo,
}) => {
  const { state, actions } = useMpv();
  const { settings } = useSettings();
  
  // ─── OSD Visibility ─────────────────────────────────
  const [osdVisible, setOsdVisible] = useState(true);
  const [showAudioMenu, setShowAudioMenu] = useState(false);
  const [showSubMenu, setShowSubMenu] = useState(false);
  const [isDraggingSeek, setIsDraggingSeek] = useState(false);
  const [seekPreviewPosition, setSeekPreviewPosition] = useState(0);
  
  const osdTimerRef = useRef<ReturnType<typeof setTimeout> | null>(null);
  const containerRef = useRef<HTMLDivElement>(null);

  // ─── Load stream when URL changes ───────────────────
  useEffect(() => {
    if (!streamUrl) return;
    if (streamType === 'live') {
      actions.loadLiveStream(streamUrl);
    } else {
      actions.loadVodStream(streamUrl, startPosition);
    }
    return () => {
      // Don't auto-stop on unmount — let caller control via stop()
    };
  }, [streamUrl, streamType]);

  // ─── Handle VOD ended ───────────────────────────────
  useEffect(() => {
    const handler = () => onEnded?.();
    window.electronAPI.on('mpv:vod-ended', handler);
    return () => window.electronAPI.off('mpv:vod-ended', handler);
  }, [onEnded]);

  // ─── OSD Auto-hide ──────────────────────────────────
  const showOsd = useCallback(() => {
    setOsdVisible(true);
    if (osdTimerRef.current) clearTimeout(osdTimerRef.current);
    if (state.isPlaying && !isDraggingSeek) {
      osdTimerRef.current = setTimeout(() => {
        setOsdVisible(false);
        setShowAudioMenu(false);
        setShowSubMenu(false);
      }, settings.osdTimeoutMs ?? 5000);
    }
  }, [state.isPlaying, isDraggingSeek, settings.osdTimeoutMs]);

  // ─── Keyboard Shortcuts ─────────────────────────────
  useEffect(() => {
    const handleKey = (e: KeyboardEvent) => {
      // Don't capture when typing in inputs
      const tag = (e.target as HTMLElement).tagName;
      if (['INPUT', 'TEXTAREA', 'SELECT'].includes(tag)) return;

      showOsd();

      switch (e.key) {
        case ' ':
        case 'k': e.preventDefault(); actions.togglePlayPause(); break;
        case 'ArrowRight':
          e.preventDefault();
          if (streamType === 'vod') {
            const delta = e.shiftKey ? 30 : e.ctrlKey ? 60 : 10;
            actions.seekRelative(delta);
          } else {
            onChannelUp?.();
          }
          break;
        case 'ArrowLeft':
          e.preventDefault();
          if (streamType === 'vod') {
            const delta = e.shiftKey ? -30 : e.ctrlKey ? -60 : -10;
            actions.seekRelative(delta);
          } else {
            onChannelDown?.();
          }
          break;
        case 'ArrowUp':
          e.preventDefault();
          actions.setVolume(Math.min(1, state.volume + 0.05));
          break;
        case 'ArrowDown':
          e.preventDefault();
          actions.setVolume(Math.max(0, state.volume - 0.05));
          break;
        case 'm': actions.setMute(!state.muted); break;
        case 's': actions.stop(); onBack?.(); break;
        case 'F12':
        case 'p': actions.takeScreenshot(); break;
        case 'Escape': onBack?.(); break;
      }
    };
    window.addEventListener('keydown', handleKey);
    return () => window.removeEventListener('keydown', handleKey);
  }, [state.volume, state.muted, streamType, actions, onBack, onChannelUp, onChannelDown, showOsd]);

  // ─── Seek bar interaction ────────────────────────────
  const handleSeekBarClick = useCallback((e: React.MouseEvent<HTMLDivElement>) => {
    if (streamType === 'live' || state.duration === 0) return;
    const bar = e.currentTarget.getBoundingClientRect();
    const pct = (e.clientX - bar.left) / bar.width;
    actions.seek(pct * state.duration);
  }, [streamType, state.duration, actions]);

  const handleSeekBarHover = useCallback((e: React.MouseEvent<HTMLDivElement>) => {
    if (streamType === 'live' || state.duration === 0) return;
    const bar = e.currentTarget.getBoundingClientRect();
    const pct = (e.clientX - bar.left) / bar.width;
    setSeekPreviewPosition(pct * state.duration);
  }, [streamType, state.duration]);

  // ─── Progress Percentage ────────────────────────────
  const progressPct = state.duration > 0
    ? (state.position / state.duration) * 100
    : 0;

  // ─── Stream Health Indicator ─────────────────────────
  // Map buffer % → quality level for display
  const bufferQuality = (() => {
    const b = state.bufferingPercent;
    if (b < 25) return 'critical';
    if (b < 50) return 'poor';
    if (b < 80) return 'good';
    return 'excellent';
  })();

  const qualityColors = {
    critical:  '#ef4444',
    poor:      '#eab308',
    good:      '#00FFFF',
    excellent: '#22c55e',
  };

  // ─── Render ──────────────────────────────────────────
  return (
    <div
      ref={containerRef}
      className="relative w-full h-full bg-black select-none"
      onMouseMove={showOsd}
      onClick={showOsd}
      style={{ cursor: osdVisible ? 'default' : 'none' }}
    >
      {/* ──────────────────────────────────────────────
          VIDEO AREA
          MPV renders in its own native layer underneath.
          This div is a transparent placeholder that:
          1. Establishes the layout space
          2. Receives mouse/keyboard events for OSD
          3. Lets you layer React UI on top
      ─────────────────────────────────────────────── */}
      <div className="absolute inset-0 bg-transparent" />

      {/* ── Loading State ─────────────────────────── */}
      {state.isLoading && (
        <div className="absolute inset-0 flex flex-col items-center justify-center bg-black/70 z-10">
          <Loader2 className="w-12 h-12 animate-spin text-cyan-400 mb-4" />
          {state.reconnectAttempt > 0 ? (
            <div className="text-center">
              <p className="text-white text-lg font-semibold">Reconnecting...</p>
              <p className="text-cyan-400 text-sm mt-1">
                Attempt {state.reconnectAttempt} of {state.reconnectMaxAttempts}
                {state.reconnectDelayMs > 0 && ` • Retry in ${Math.round(state.reconnectDelayMs / 1000)}s`}
              </p>
            </div>
          ) : (
            <p className="text-white text-lg">Loading stream...</p>
          )}
        </div>
      )}

      {/* ── Error State ───────────────────────────── */}
      {state.error && !state.isLoading && (
        <div className="absolute inset-0 flex flex-col items-center justify-center bg-black/80 z-10">
          <AlertCircle className="w-12 h-12 text-red-400 mb-4" />
          <p className="text-white text-lg font-semibold mb-2">Playback Error</p>
          <p className="text-red-300 text-sm text-center max-w-md px-4">{state.error}</p>
          <button
            onClick={() => streamUrl && (streamType === 'live'
              ? actions.loadLiveStream(streamUrl)
              : actions.loadVodStream(streamUrl, state.position)
            )}
            className="mt-4 px-6 py-2 bg-cyan-600 hover:bg-cyan-500 text-white rounded-lg transition-colors"
          >
            <RotateCcw className="w-4 h-4 inline mr-2" />
            Retry
          </button>
        </div>
      )}

      {/* ── MPV Unavailable Fallback ───────────────── */}
      {!state.isAvailable && (
        <div className="absolute inset-0 flex flex-col items-center justify-center bg-black/90 z-10">
          <WifiOff className="w-12 h-12 text-yellow-400 mb-4" />
          <p className="text-white text-lg font-semibold">MPV Not Available</p>
          <p className="text-gray-400 text-sm text-center max-w-md px-4 mt-2">
            Falling back to built-in HLS player. Some features may be limited.

      {/* ──────────────────────────────────────────────

              <button
                onClick={() => { actions.stop(); onBack(); }}
                className="text-white hover:text-cyan-400 transition-colors p-2 rounded-lg hover:bg-white/10"

                <ChevronLeft className="w-6 h-6" />

            )}
            {channelLogo && (
              <img src={channelLogo} alt="" className="h-8 object-contain" />
            )}
            <div>
              <p className="text-white font-bold text-lg leading-tight">{streamTitle}</p>
              {epgCurrentProgram && (
                <p className="text-cyan-300 text-sm">
                  {epgCurrentProgram.title} •{' '}
                  {new Date(epgCurrentProgram.startTime).toLocaleTimeString([], { hour: '2-digit', minute: '2-digit' })}–
                  {new Date(epgCurrentProgram.endTime).toLocaleTimeString([], { hour: '2-digit', minute: '2-digit' })}
                </p>

            {/* Stream Health */}
```

### 5.1 Create `src/components/VideoPlayerEngine.tsx`

```tsx
// src/components/VideoPlayerEngine.tsx
// ─────────────────────────────────────────────────────────
// Smart engine selector — routes streams to MPV or hls.js
// based on availability and stream type
// ─────────────────────────────────────────────────────────

import React, { useState, useEffect } from 'react';
import { MpvPlayer } from './MpvPlayer';
import { VideoPlayer } from './VideoPlayer'; // Your existing hls.js player
import { useSettingsStore } from '../store/useSettingsStore';

type PlayerEngine = 'mpv' | 'hlsjs';

interface VideoPlayerEngineProps {
  streamUrl: string | null;
  streamType: 'live' | 'vod';
  streamTitle: string;
  onBack?: () => void;
  onEnded?: () => void;
  onChannelUp?: () => void;
  onChannelDown?: () => void;
  startPosition?: number;
  epgCurrentProgram?: any;
  epgNextProgram?: any;
  channelLogo?: string;
}

// Determine which engine to use for a given stream URL
function selectEngine(
  url: string,
  streamType: 'live' | 'vod',
  mpvAvailable: boolean,
  preferredEngine: PlayerEngine
): PlayerEngine {
  if (!mpvAvailable) return 'hlsjs';
  if (preferredEngine === 'hlsjs') return 'hlsjs';
  
  // MPV handles everything better for IPTV
  return 'mpv';
}

export const VideoPlayerEngine: React.FC<VideoPlayerEngineProps> = (props) => {
  const { settings } = useSettingsStore();
  const [mpvAvailable, setMpvAvailable] = useState(true);
  const [activeEngine, setActiveEngine] = useState<PlayerEngine>('mpv');
  const [engineError, setEngineError] = useState<string | null>(null);

  // Listen for MPV availability
  useEffect(() => {
    const handleUnavailable = () => {
      setMpvAvailable(false);
      setActiveEngine('hlsjs');
    };
    const handleReady = () => {
      setMpvAvailable(true);
    };
    window.electronAPI?.on('mpv:unavailable', handleUnavailable);
    window.electronAPI?.on('mpv:ready', handleReady);
    return () => {
      window.electronAPI?.off('mpv:unavailable', handleUnavailable);
      window.electronAPI?.off('mpv:ready', handleReady);
    };
  }, []);

  // Determine engine for current stream
  useEffect(() => {
    if (!props.streamUrl) return;
    const engine = selectEngine(
      props.streamUrl,
      props.streamType,
      mpvAvailable,
      (settings as any).preferredEngine ?? 'mpv'
    );
    setActiveEngine(engine);
    setEngineError(null);
  }, [props.streamUrl, props.streamType, mpvAvailable, settings]);

  return (
    <div className="relative w-full h-full bg-black">
      {/* Engine indicator badge (dev mode or settings opt-in) */}
      {process.env.NODE_ENV === 'development' && (
        <div className="absolute top-2 left-2 z-50 text-xs bg-black/80 text-cyan-400 px-2 py-1 rounded font-mono pointer-events-none">
          Engine: {activeEngine.toUpperCase()}
        </div>
      )}

      {/* Render the selected engine */}
      {activeEngine === 'mpv' ? (
        <MpvPlayer {...props} />
      ) : (
        <VideoPlayer
          url={props.streamUrl}
          title={props.streamTitle}
          streamType={props.streamType}
          onBack={props.onBack}
          onEnded={props.onEnded}
          startPosition={props.startPosition}
        />
      )}
    </div>
  );
};
```
