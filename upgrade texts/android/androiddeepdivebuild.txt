## 🧠 CRITICAL ARCHITECTURE DECISIONS FIRST

Before one line of code, these three decisions define every other choice:

### Decision 1: Native Android (Kotlin) — Not React Native

You are targeting the Fire TV Stick 4K as your primary device. That means:

- The Fire TV Stick 4K runs Fire OS 8 based on Android 11, and is powered by a quad-core MediaTek MT8696D processor clocked at 1.7GHz — a 32-bit chipset.
- The Fire TV Stick 4K Max 2023 is powered by the MediaTek MT8696T, with a slightly higher clock speed at 2.0 GHz.
- The Fire TV Stick 4K Max has 2GB of RAM, with 16GB of storage.
- Amazon is limiting all their devices with a 32-bit version of Android, thereby limiting the full performance of the SoCs they use, since there is no support for 64-bit applications on these devices.

This means **React Native is off the table**. With only 2GB RAM shared between the OS, Fire OS launcher, your app, LibVLC engine, mpv engine, AND two simultaneous recording pipelines, every megabyte of overhead matters. Native Kotlin with Jetpack Compose gives you the lowest possible memory footprint with the highest performance ceiling.

### Decision 2: Dual Engine Assignment

| Engine | Assigned Role | Reason |
|---|---|---|
| **LibVLC** | Live TV + EPG Guide playback | Superior IPTV stream handling, built-in reconnect, best low-latency TS/HLS support, handles `.ts`, `RTSP`, `RTMP`, `MPEG-TS UDP` natively |
| **mpv (libmpv)** | VOD — Movies + TV Series | Superior codec breadth (H.265/HEVC, AV1, HDR), precision seeking, subtitle rendering (ASS/SSA/PGS), chapter support, better for file-like streams |

### Decision 3: Recording Architecture

You need: **Record 2 simultaneously + Watch a 3rd**. That means 3 independent decode/output pipelines must coexist within 2GB RAM. The architecture:

```
LibVLC Instance A → Live TV Watching (foreground SurfaceView)
LibVLC Instance B → Recording Stream 1 (background, no video output, muxed to file)
LibVLC Instance C → Recording Stream 2 (background, no video output, muxed to file)
```

All three can coexist because LibVLC instances B and C use **`--vout=dummy`** (no video rendering) — they only demux and mux to file, consuming ~40–80MB RAM each instead of 200MB+ for full decode. LibVLC instance A handles the full watched stream.

### 0.2 Critical ABI Note for Fire TV

The Fire TV Stick's Cortex-A55 cores are 64-bit ARM64/v8-A based, but Amazon is limiting devices with a 32-bit version of Android, so there is no support for 64-bit applications on these devices.

This means your `build.gradle.kts` MUST include:

```kotlin
// app/build.gradle.kts
android {
    defaultConfig {
        applicationId = "com.dylandos.iptv.ultimate.android"
        minSdk = 28
        targetSdk = 33  // Fire OS 8 = Android 11, max tested = API 33
        versionCode = 1
        versionName = "1.0.0"

        // ── CRITICAL: Fire TV Stick 4K is 32-bit only ──
        ndk {
            abiFilters += listOf("armeabi-v7a")  // Primary Fire TV target
            // Add arm64-v8a for future-proofing on Android phone/tablet builds
            // abiFilters += listOf("armeabi-v7a", "arm64-v8a")
        }
    }

    buildFeatures {
        compose = true
    }
    
    composeOptions {
        kotlinCompilerExtensionVersion = "1.5.14"
    }
    
    // Optimize for Fire TV Stick's limited storage
    bundle {
        abi { enableSplit = true }
        density { enableSplit = false }  // TV is always full density
    }
}
```

## 🎭 PHASE 1 — LIBVLC ENGINE: LIVE TV

You can use the LibVLC module to power your own Android media player by downloading the `.aar` directly from Maven or building from source.

LibVLC can play every media file format, every codec, and every streaming protocol including RTSP, RTMP, Multicast, HLS/DASH/HDS, and more, running on every platform from desktop to mobile, TV, and consoles.

### 1.1 `LibVlcEngine.kt` — The Singleton Manager

```kotlin
// core/engine/LibVlcEngine.kt
package com.dylandos.iptv.ultimate.core.engine

import android.content.Context
import android.net.Uri
import android.view.SurfaceView
import dagger.hilt.android.qualifiers.ApplicationContext
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import org.videolan.libvlc.LibVLC
import org.videolan.libvlc.Media
import org.videolan.libvlc.MediaPlayer
import org.videolan.libvlc.util.VLCVideoLayout
import javax.inject.Inject
import javax.inject.Singleton

// ─── State model ──────────────────────────────────────────
data class VlcPlayerState(
    val isPlaying: Boolean = false,
    val isBuffering: Boolean = false,
    val isLoading: Boolean = false,
    val error: String? = null,
    val position: Float = 0f,      // 0.0–1.0
    val time: Long = 0L,           // milliseconds
    val duration: Long = 0L,       // milliseconds
    val volume: Int = 100,         // 0–200
    val muted: Boolean = false,
    val bufferPercent: Int = 0,
    val videoWidth: Int = 0,
    val videoHeight: Int = 0,
    val audioTrackCount: Int = 0,
    val spuTrackCount: Int = 0,
    val reconnectAttempt: Int = 0,
    val reconnectMax: Int = 10,
)

@Singleton
class LibVlcEngine @Inject constructor(
    @ApplicationContext private val context: Context
) {

    // ─── LibVLC instance with optimized Fire TV Stick 4K args ──
    private val libVLC: LibVLC by lazy {
        LibVLC(context, buildVlcArgs())
    }

    // ─── Primary playback player ───────────────────────────────
    private var primaryPlayer: MediaPlayer? = null

    // ─── State flow ────────────────────────────────────────────
    private val _state = MutableStateFlow(VlcPlayerState())
    val state: StateFlow<VlcPlayerState> = _state.asStateFlow()

    // ─── Reconnect state ───────────────────────────────────────
    private var reconnectJob: kotlinx.coroutines.Job? = null
    private var reconnectAttempts = 0
    private var currentUrl: String? = null
    private val maxReconnectAttempts = 10
    private val baseReconnectDelayMs = 2000L

    // ──────────────────────────────────────────────────────────
    // BUILD VLC ARGS — Fire TV Stick 4K Optimized
    // ──────────────────────────────────────────────────────────
    private fun buildVlcArgs(): ArrayList<String> = arrayListOf(
        // ── Output module optimized for Android ──
        "--vout=android-display",       // Android-native video output
        "--aout=opensles",              // OpenSL ES audio — best on older Android

        // ── Low-latency live streaming ──
        "--network-caching=1500",       // 1.5s network buffer (balanced for Fire TV WiFi)
        "--live-caching=300",           // 300ms live capture cache
        "--clock-jitter=0",             // No jitter correction for live
        "--clock-synchro=0",            // Disable A/V sync correction (low latency)

        // ── Frame handling for weak SoC ──
        "--drop-late-frames",           // Drop frames arriving late
        "--skip-frames",                // Skip frames if decode is too slow

        // ── Hardware decode ──
        "--codec=mediacodec_ndk,all",   // Prefer MediaCodec NDK (hardware), fallback to all
        // MediaCodec NDK is the preferred HW decode path on Fire OS

        // ── Reconnect on error ──
        "--http-reconnect",             // Auto-reconnect HTTP streams
        "--http-continuous",            // Keep HTTP connection alive
        "--rtsp-tcp",                   // Use TCP for RTSP (more reliable on WiFi)

        // ── Subtitle rendering ──
        "--sub-filter=freetype",        // FreeType subtitle rendering

        // ── Performance: Fire TV Stick 4K has 1 GPU core ──
        "--no-video-title-show",        // Don't render title overlay
        "--avcodec-fast",               // Favor speed over quality in SW decode

        // ── Logging ──
        // Remove -vvv in production — it hammers logcat and CPU
        // "--vvv",  // ← ONLY in debug builds
    )

    // ──────────────────────────────────────────────────────────
    // ATTACH VIDEO OUTPUT
    // ──────────────────────────────────────────────────────────
    fun attachVideoLayout(layout: VLCVideoLayout) {
        primaryPlayer?.attachViews(layout, null, ENABLE_SUBTITLES, USE_TEXTURE_VIEW)
    }

    fun detachVideoLayout() {
        primaryPlayer?.detachViews()
    }

    // ──────────────────────────────────────────────────────────
    // LOAD & PLAY LIVE STREAM
    // ──────────────────────────────────────────────────────────
    fun loadLiveStream(url: String, bufferPreset: BufferPreset = BufferPreset.MEDIUM) {
        currentUrl = url
        reconnectAttempts = 0

        // Release previous player cleanly
        releasePlayer()

        // Create fresh player
        primaryPlayer = MediaPlayer(libVLC).apply {
            attachEventListener(primaryEventListener)
        }

        _state.value = VlcPlayerState(isLoading = true)

        val media = Media(libVLC, Uri.parse(url)).apply {
            // Per-stream caching tuned to preset
            addOption(":network-caching=${bufferPreset.networkCachingMs}")
            addOption(":live-caching=${bufferPreset.liveCachingMs}")
            addOption(":file-caching=300")
            addOption(":http-reconnect")
            // Hardware decode
            setHWDecoderEnabled(true, false)  // true=enable, false=don't force
        }

        primaryPlayer?.media = media
        media.release()
        primaryPlayer?.play()
    }

    // ──────────────────────────────────────────────────────────
    // PLAYBACK CONTROLS
    // ──────────────────────────────────────────────────────────
    fun play()   { primaryPlayer?.play() }
    fun pause()  { primaryPlayer?.pause() }
    fun stop()   {
        reconnectJob?.cancel()
        releasePlayer()
        _state.value = VlcPlayerState()
    }

    fun setVolume(volume: Int) {
        // VLC volume: 0–200 (100 = normal, 200 = double)
        primaryPlayer?.volume = volume.coerceIn(0, 200)
        _state.value = _state.value.copy(volume = volume)
    }

    fun setMute(muted: Boolean) {
        primaryPlayer?.volume = if (muted) 0 else _state.value.volume
        _state.value = _state.value.copy(muted = muted)
    }

    fun setAudioTrack(trackId: Int) {
        primaryPlayer?.audioTrack = trackId
    }

    fun setSubtitleTrack(trackId: Int) {
        primaryPlayer?.spuTrack = trackId
    }

    fun setAudioDelay(delayMicroseconds: Long) {
        // VLC audio delay is in MICROSECONDS (not ms!)
        primaryPlayer?.audioDelay = delayMicroseconds
    }

    fun getAudioTracks(): List<MediaPlayer.TrackDescription>? {
        return primaryPlayer?.audioTracks?.toList()
    }

    fun getSubtitleTracks(): List<MediaPlayer.TrackDescription>? {
        return primaryPlayer?.spuTracks?.toList()
    }

    // ──────────────────────────────────────────────────────────
    // EVENT LISTENER (Primary Player)
    // ──────────────────────────────────────────────────────────
    private val primaryEventListener = MediaPlayer.EventListener { event ->
        when (event.type) {
            MediaPlayer.Event.Playing -> {
                reconnectAttempts = 0
                _state.value = _state.value.copy(
                    isPlaying = true,
                    isLoading = false,
                    isBuffering = false,
                    error = null,
                    reconnectAttempt = 0,
                )
            }

            MediaPlayer.Event.Paused -> {
                _state.value = _state.value.copy(isPlaying = false)
            }

            MediaPlayer.Event.Stopped -> {
                _state.value = _state.value.copy(isPlaying = false, isLoading = false)
            }

            MediaPlayer.Event.Buffering -> {
                val pct = event.buffering.toInt()
                _state.value = _state.value.copy(
                    isBuffering = pct < 100,
                    bufferPercent = pct,
                )
            }

            MediaPlayer.Event.TimeChanged -> {
                _state.value = _state.value.copy(time = event.timeChanged)
            }

            MediaPlayer.Event.PositionChanged -> {
                _state.value = _state.value.copy(position = event.positionChanged)
            }

            MediaPlayer.Event.LengthChanged -> {
                _state.value = _state.value.copy(duration = event.lengthChanged)
            }

            MediaPlayer.Event.Vout -> {
                // Video output surface count changed — update resolution
                primaryPlayer?.currentVideoTrack?.let { track ->
                    _state.value = _state.value.copy(
                        videoWidth = track.width,
                        videoHeight = track.height
                    )
                }
            }

            MediaPlayer.Event.EncounteredError -> {
                handlePlaybackError()
            }

            MediaPlayer.Event.EndReached -> {
                // For live streams, EndReached usually means stream dropped
                if (currentUrl != null) {
                    handlePlaybackError()
                }
            }
        }
    }

    // ──────────────────────────────────────────────────────────
    // ERROR HANDLING + RECONNECT
    // ──────────────────────────────────────────────────────────
    private fun handlePlaybackError() {
        if (reconnectAttempts >= maxReconnectAttempts) {
            _state.value = _state.value.copy(
                error = "Stream unavailable after $maxReconnectAttempts attempts",
                isLoading = false,
                isPlaying = false,
            )
            return
        }

        reconnectAttempts++
        // Exponential backoff capped at 30s
        val delayMs = minOf(
            baseReconnectDelayMs * Math.pow(2.0, (reconnectAttempts - 1).toDouble()).toLong(),
            30_000L
        )

        _state.value = _state.value.copy(
            isLoading = true,
            isPlaying = false,
            error = null,
            reconnectAttempt = reconnectAttempts,
            reconnectMax = maxReconnectAttempts,
        )

        reconnectJob?.cancel()
        reconnectJob = kotlinx.coroutines.GlobalScope.launch {
            kotlinx.coroutines.delay(delayMs)
            currentUrl?.let { url ->
                // Re-create media and play
                val media = Media(libVLC, Uri.parse(url)).apply {
                    addOption(":network-caching=1500")
                    addOption(":http-reconnect")
                    setHWDecoderEnabled(true, false)
                }
                primaryPlayer?.media = media
                media.release()
                primaryPlayer?.play()
            }
        }
    }

    // ──────────────────────────────────────────────────────────
    // CLEANUP
    // ──────────────────────────────────────────────────────────
    private fun releasePlayer() {
        primaryPlayer?.apply {
            stop()
            detachViews()
            release()
        }
        primaryPlayer = null
    }

    fun destroy() {
        reconnectJob?.cancel()
        releasePlayer()
        libVLC.release()
    }

    companion object {
        private const val ENABLE_SUBTITLES = true
        private const val USE_TEXTURE_VIEW = false  // SurfaceView for hardware decode
    }
}

// ─── Buffer Presets ─────────────────────────────────────────
enum class BufferPreset(val networkCachingMs: Int, val liveCachingMs: Int) {
    LOW(500, 150),
    MEDIUM(1500, 300),
    HIGH(3000, 600),
}
```

```kotlin
                val type = track["type"]?.toString()?.trim('"') ?: return@forEach

                    id = track["id"]?.toString()?.toIntOrNull() ?: 0,
                    title = track["title"]?.toString()?.trim('"') ?: "",

                    selected = track["selected"]?.toString() == "true",

                    "audio" -> audioTracks.add(t)
                    "sub" -> subTracks.add(t)
                }
            }

            _state.value = _state.value.copy(
                audioTracks = audioTracks,
                subtitleTracks = subTracks,
            )

            // Ignore parse errors
        }
```

## 📹 PHASE 3 — DUAL RECORDING SYSTEM

### 3.2 `RecordingManager.kt`

```kotlin
// core/recording/RecordingManager.kt
package com.dylandos.iptv.ultimate.core.recording

import android.content.Context
import android.net.Uri
import android.os.Environment
import dagger.hilt.android.qualifiers.ApplicationContext
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import org.videolan.libvlc.LibVLC
import org.videolan.libvlc.Media
import org.videolan.libvlc.MediaPlayer
import java.io.File
import java.text.SimpleDateFormat
import java.util.*
import javax.inject.Inject
import javax.inject.Singleton

// ─── Recording Session Model ────────────────────────────────
data class RecordingSession(
    val id: String = UUID.randomUUID().toString(),
    val channelName: String,
    val channelId: String,
    val streamUrl: String,
    val outputFilePath: String,
    val startTime: Long = System.currentTimeMillis(),
    val status: RecordingStatus = RecordingStatus.STARTING,
    val durationMs: Long = 0L,
    val fileSizeBytes: Long = 0L,
    val scheduledEndTime: Long? = null,  // null = manual stop
)

enum class RecordingStatus {
    STARTING, RECORDING, PAUSED, STOPPING, COMPLETED, ERROR
}

data class RecordingManagerState(
    val slot1: RecordingSession? = null,
    val slot2: RecordingSession? = null,
    val canRecord: Boolean = true,  // false if both slots full
    val totalRecordingDurationMs: Long = 0L,
)

// ──────────────────────────────────────────────────────────────
@Singleton
class RecordingManager @Inject constructor(
    @ApplicationContext private val context: Context,
    private val recordingDao: RecordingDao,
) {
    // ── Separate LibVLC instances for recording ──────────────
    // These are SEPARATE from LibVlcEngine's primary player
    private val recordingLibVLC1: LibVLC by lazy { createRecordingLibVLC() }
    private val recordingLibVLC2: LibVLC by lazy { createRecordingLibVLC() }

    private var recordingPlayer1: MediaPlayer? = null
    private var recordingPlayer2: MediaPlayer? = null

    private val _state = MutableStateFlow(RecordingManagerState())
    val state: StateFlow<RecordingManagerState> = _state.asStateFlow()

    // Duration tracking
    private val startTimes = mutableMapOf<String, Long>()
    private val durationTimer = java.util.Timer()

    init {
        // Update durations every second
        durationTimer.scheduleAtFixedRate(object : java.util.TimerTask() {
            override fun run() { updateDurations() }
        }, 1000L, 1000L)
    }

    // ──────────────────────────────────────────────────────────
    // CREATE RECORDING-OPTIMIZED LIBVLC INSTANCE
    // ──────────────────────────────────────────────────────────
    private fun createRecordingLibVLC(): LibVLC {
        return LibVLC(context, arrayListOf(
            // ── KEY: No video output — saves significant RAM and CPU ──
            "--vout=dummy",           // Null video output — no rendering
            "--no-video",             // Completely disable video decoding path
                                      // We don't need decoded video frames for recording

            // ── Audio output also disabled for background recording ──
            "--aout=dummy",           // Null audio output

            // ── Network settings optimized for reliable capture ──
            "--network-caching=3000", // Larger buffer for recording reliability
            "--http-reconnect",
            "--http-continuous",

            // ── Recording-specific: don't drop frames ──
            // (opposite of live playback — we want every frame captured)
            // No --drop-late-frames here!
            // No --skip-frames here!
        ))
    }

    // ──────────────────────────────────────────────────────────
    // START RECORDING — SLOT 1 OR 2
    // ──────────────────────────────────────────────────────────
    suspend fun startRecording(
        channelName: String,
        channelId: String,
        streamUrl: String,
        scheduledDurationMinutes: Int? = null,  // null = manual
    ): Result<RecordingSession> {

        val currentState = _state.value

        // Find available slot
        val slot = when {
            currentState.slot1 == null -> 1
            currentState.slot2 == null -> 2
            else -> return Result.failure(
                IllegalStateException("Both recording slots are in use")
            )
        }

        // Build output file path
        val outputFile = buildOutputFile(channelName)
        val scheduledEnd = scheduledDurationMinutes?.let {
            System.currentTimeMillis() + (it * 60_000L)
        }

        val session = RecordingSession(
            channelName = channelName,
            channelId = channelId,
            streamUrl = streamUrl,
            outputFilePath = outputFile.absolutePath,
            scheduledEndTime = scheduledEnd,
        )

        // Build LibVLC sout (stream output) string for muxing to file
        // This is the CORE of how LibVLC records:
        // :sout= tells VLC where to send the stream instead of displaying it
        val soutString = buildSoutString(outputFile.absolutePath)

        return try {
            when (slot) {
                1 -> startRecordingOnSlot1(session, streamUrl, soutString)
                2 -> startRecordingOnSlot2(session, streamUrl, soutString)
                else -> throw IllegalStateException("Invalid slot")
            }

            // Persist to database
            recordingDao.insertRecording(session.toEntity())

            // Schedule auto-stop if duration specified
            scheduledEnd?.let { endTime ->
                scheduleAutoStop(session.id, endTime - System.currentTimeMillis())
            }

            Result.success(session)
        } catch (e: Exception) {
            Result.failure(e)
        }
    }

    // ──────────────────────────────────────────────────────────
    // BUILD VLC SOUT STRING — The Recording Magic
    // ──────────────────────────────────────────────────────────
    // VLC's stream output (sout) chain:
    // #duplicate → splits the stream
    // transcode → re-encode (optional, we use copy for efficiency)
    // std → standard output module with access=file
    private fun buildSoutString(outputPath: String): String {
        // Most efficient: copy the stream without re-encoding
        // This preserves original H.264/H.265 quality with ZERO CPU overhead
        return "#std{access=file,mux=ts,dst=$outputPath}"

        // Alternative: if you need re-encoding (e.g., for compatibility):
        // "#transcode{vcodec=h264,vb=0,acodec=aac,ab=128}:std{access=file,mux=mp4,dst=$outputPath}"
    }

    private fun startRecordingOnSlot1(
        session: RecordingSession,
        streamUrl: String,
        soutString: String,
    ) {
        recordingPlayer1 = MediaPlayer(recordingLibVLC1)

        val media = Media(recordingLibVLC1, Uri.parse(streamUrl)).apply {
            addOption(":sout=$soutString")
            addOption(":sout-keep")  // Keep the sout chain active
            addOption(":network-caching=3000")
            // No hardware decode needed for recording without display
            setHWDecoderEnabled(false, false)
        }

        recordingPlayer1?.media = media
        media.release()
        recordingPlayer1?.play()

        startTimes[session.id] = System.currentTimeMillis()
        _state.value = _state.value.copy(
            slot1 = session.copy(status = RecordingStatus.RECORDING),
            canRecord = _state.value.slot2 == null,
        )
    }

    private fun startRecordingOnSlot2(
        session: RecordingSession,
        streamUrl: String,
        soutString: String,
    ) {
        recordingPlayer2 = MediaPlayer(recordingLibVLC2)

        val media = Media(recordingLibVLC2, Uri.parse(streamUrl)).apply {
            addOption(":sout=$soutString")
            addOption(":sout-keep")
            addOption(":network-caching=3000")
            setHWDecoderEnabled(false, false)
        }

        recordingPlayer2?.media = media
        media.release()
        recordingPlayer2?.play()

        startTimes[session.id] = System.currentTimeMillis()
        _state.value = _state.value.copy(
            slot2 = session.copy(status = RecordingStatus.RECORDING),
            canRecord = false,  // Both slots now in use
        )
    }

    // ──────────────────────────────────────────────────────────
    // STOP RECORDING
    // ──────────────────────────────────────────────────────────
    suspend fun stopRecording(sessionId: String) {
        val currentState = _state.value

        when {
            currentState.slot1?.id == sessionId -> {
                recordingPlayer1?.stop()
                recordingPlayer1?.release()
                recordingPlayer1 = null
                startTimes.remove(sessionId)
                _state.value = _state.value.copy(
                    slot1 = null,
                    canRecord = true,
                )
                recordingDao.markCompleted(sessionId, System.currentTimeMillis())
            }
            currentState.slot2?.id == sessionId -> {
                recordingPlayer2?.stop()
                recordingPlayer2?.release()
                recordingPlayer2 = null
                startTimes.remove(sessionId)
                _state.value = _state.value.copy(
                    slot2 = null,
                    canRecord = true,
                )
                recordingDao.markCompleted(sessionId, System.currentTimeMillis())
            }
        }
    }

    // ──────────────────────────────────────────────────────────
    // AUTO-STOP SCHEDULING
    // ──────────────────────────────────────────────────────────
    private fun scheduleAutoStop(sessionId: String, delayMs: Long) {
        // Use Android Handler for auto-stop within foreground service
        android.os.Handler(android.os.Looper.getMainLooper()).postDelayed({
            kotlinx.coroutines.runBlocking { stopRecording(sessionId) }
        }, delayMs)
    }

    // ──────────────────────────────────────────────────────────
    // DURATION TRACKING
    // ──────────────────────────────────────────────────────────
    private fun updateDurations() {
        val now = System.currentTimeMillis()
        val currentState = _state.value

        val updatedSlot1 = currentState.slot1?.let { session ->
            val elapsed = now - (startTimes[session.id] ?: now)
            val file = File(session.outputFilePath)
            session.copy(
                durationMs = elapsed,
                fileSizeBytes = if (file.exists()) file.length() else 0L
            )
        }

        val updatedSlot2 = currentState.slot2?.let { session ->
            val elapsed = now - (startTimes[session.id] ?: now)
            val file = File(session.outputFilePath)
            session.copy(
                durationMs = elapsed,
                fileSizeBytes = if (file.exists()) file.length() else 0L
            )
        }

        if (updatedSlot1 != currentState.slot1 || updatedSlot2 != currentState.slot2) {
            _state.value = _state.value.copy(
                slot1 = updatedSlot1,
                slot2 = updatedSlot2,
            )
        }
    }

    // ──────────────────────────────────────────────────────────
    // BUILD OUTPUT FILE PATH
    // ──────────────────────────────────────────────────────────
    private fun buildOutputFile(channelName: String): File {
        // Save to Movies/DylandosRecordings/ on Fire TV
        // Fire TV doesn't have external SD, so use internal Movies dir
        val recordingsDir = File(
            context.getExternalFilesDir(Environment.DIRECTORY_MOVIES),
            "DylandosIPTV"
        ).also { it.mkdirs() }

        val timestamp = SimpleDateFormat("yyyy-MM-dd_HH-mm-ss", Locale.US)
            .format(Date())
        val safeName = channelName.replace(Regex("[^a-zA-Z0-9\\s]"), "")
            .replace(Regex("\\s+"), "_")
            .take(40)

        return File(recordingsDir, "${safeName}_${timestamp}.ts")
    }

    // ──────────────────────────────────────────────────────────
    // CLEANUP
    // ──────────────────────────────────────────────────────────
    fun destroy() {
        durationTimer.cancel()
        recordingPlayer1?.stop()
        recordingPlayer1?.release()
        recordingPlayer2?.stop()
        recordingPlayer2?.release()
        recordingLibVLC1.release()
        recordingLibVLC2.release()
    }
```

### 3.3 `RecordingService.kt` — Android Foreground Service

This is **mandatory**. Without it, Android will kill your background recording processes after 60 seconds when the app goes to background:

```kotlin
// core/recording/RecordingService.kt
package com.dylandos.iptv.ultimate.core.recording

import android.app.Notification
import android.app.NotificationChannel
import android.app.NotificationManager
import android.app.PendingIntent
import android.app.Service
import android.content.Context
import android.content.Intent
import android.os.IBinder
import androidx.core.app.NotificationCompat
import com.dylandos.iptv.ultimate.MainActivity
import com.dylandos.iptv.ultimate.R
import dagger.hilt.android.AndroidEntryPoint
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.SupervisorJob
import kotlinx.coroutines.cancel
import kotlinx.coroutines.flow.launchIn
import kotlinx.coroutines.flow.onEach
import javax.inject.Inject

@AndroidEntryPoint
class RecordingService : Service() {

    @Inject lateinit var recordingManager: RecordingManager

    private val serviceScope = CoroutineScope(SupervisorJob() + Dispatchers.Main)
    private val CHANNEL_ID = "dylandos_recording"
    private val NOTIFICATION_ID = 1001

    override fun onCreate() {
        super.onCreate()
        createNotificationChannel()

        // Start as foreground service IMMEDIATELY — critical for Android 8+
        startForeground(NOTIFICATION_ID, buildNotification(null, null))

        // Observe recording state to update notification
        recordingManager.state
            .onEach { state -> updateNotification(state) }
            .launchIn(serviceScope)
    }

    override fun onStartCommand(intent: Intent?, flags: Int, startId: Int): Int {
        return START_STICKY  // Restart if killed — keep recording alive
    }

    override fun onBind(intent: IBinder?): IBinder? = null

    override fun onDestroy() {
        serviceScope.cancel()
        super.onDestroy()
    }

    // ── Notification showing recording status ────────────────
    private fun buildNotification(slot1: RecordingSession?, slot2: RecordingSession?): Notification {
        val launchIntent = PendingIntent.getActivity(
            this, 0,
            Intent(this, MainActivity::class.java).apply {
                flags = Intent.FLAG_ACTIVITY_SINGLE_TOP
                putExtra("navigate_to", "recordings")
            },
            PendingIntent.FLAG_UPDATE_CURRENT or PendingIntent.FLAG_IMMUTABLE
        )

        val contentText = when {
            slot1 != null && slot2 != null ->
                "Recording: ${slot1.channelName} + ${slot2.channelName}"
            slot1 != null ->
                "Recording: ${slot1.channelName} • ${formatDuration(slot1.durationMs)}"
            slot2 != null ->
                "Recording: ${slot2.channelName} • ${formatDuration(slot2.durationMs)}"
            else -> "Recording service active"
        }

        return NotificationCompat.Builder(this, CHANNEL_ID)
            .setContentTitle("DYLANDOS IPTV — Recording")
            .setContentText(contentText)
            .setSmallIcon(R.drawable.ic_record_dot)  // Red dot icon
            .setColor(0xFFEF4444.toInt())            // Red accent
            .setContentIntent(launchIntent)
            .setOngoing(true)                         // Cannot be dismissed by user
            .setOnlyAlertOnce(true)                   // Don't re-alert on update
            .setPriority(NotificationCompat.PRIORITY_LOW)
            .build()
    }

    private fun updateNotification(state: RecordingManagerState) {
        val nm = getSystemService(Context.NOTIFICATION_SERVICE) as NotificationManager
        nm.notify(NOTIFICATION_ID, buildNotification(state.slot1, state.slot2))
    }

    private fun createNotificationChannel() {
        val channel = NotificationChannel(
            CHANNEL_ID,
            "DYLANDOS Recordings",
            NotificationManager.IMPORTANCE_LOW  // Low = no sound, shows in status bar
        ).apply {
            description = "Active recording sessions"
            setShowBadge(true)
        }
        (getSystemService(Context.NOTIFICATION_SERVICE) as NotificationManager)
            .createNotificationChannel(channel)
    }

    private fun formatDuration(ms: Long): String {
        val h = ms / 3_600_000
        val m = (ms % 3_600_000) / 60_000
        val s = (ms % 60_000) / 1_000
        return if (h > 0) "%d:%02d:%02d".format(h, m, s)
        else "%d:%02d".format(m, s)
    }

    companion object {
        fun start(context: Context) {
            context.startForegroundService(Intent(context, RecordingService::class.java))
        }
        fun stop(context: Context) {
            context.stopService(Intent(context, RecordingService::class.java))
        }
    }
}
```

### 3.4 Scheduled Recording via WorkManager

```kotlin
// core/recording/ScheduledRecordingWorker.kt
package com.dylandos.iptv.ultimate.core.recording

import android.content.Context
import androidx.hilt.work.HiltWorker
import androidx.work.*
import dagger.assisted.Assisted
import dagger.assisted.AssistedInject
import java.util.concurrent.TimeUnit

@HiltWorker
class ScheduledRecordingWorker @AssistedInject constructor(
    @Assisted appContext: Context,
    @Assisted workerParams: WorkerParameters,
    private val recordingManager: RecordingManager,
) : CoroutineWorker(appContext, workerParams) {

    override suspend fun doWork(): Result {
        val channelName = inputData.getString(KEY_CHANNEL_NAME) ?: return Result.failure()
        val channelId   = inputData.getString(KEY_CHANNEL_ID) ?: return Result.failure()
        val streamUrl   = inputData.getString(KEY_STREAM_URL) ?: return Result.failure()
        val durationMin = inputData.getInt(KEY_DURATION_MINUTES, 60)

        // Start the foreground recording service
        RecordingService.start(applicationContext)

        val result = recordingManager.startRecording(
            channelName = channelName,
            channelId = channelId,
            streamUrl = streamUrl,
            scheduledDurationMinutes = durationMin,
        )

        return if (result.isSuccess) Result.success()
        else Result.retry()
    }

    companion object {
        const val KEY_CHANNEL_NAME = "channel_name"
        const val KEY_CHANNEL_ID = "channel_id"
        const val KEY_STREAM_URL = "stream_url"
        const val KEY_DURATION_MINUTES = "duration_minutes"

        // Schedule a recording via WorkManager
        fun schedule(
            context: Context,
            workManager: WorkManager,
            channelName: String,
            channelId: String,
            streamUrl: String,
            startTimeMs: Long,           // When to begin recording
            durationMinutes: Int,        // How long to record
            paddingStartMs: Long = 120_000L,   // Start 2 min early
        ) {
            val delay = maxOf(0L, (startTimeMs - paddingStartMs) - System.currentTimeMillis())

            val workData = workDataOf(
                KEY_CHANNEL_NAME to channelName,
                KEY_CHANNEL_ID to channelId,
                KEY_STREAM_URL to streamUrl,
                KEY_DURATION_MINUTES to durationMinutes,
            )

            val request = OneTimeWorkRequestBuilder<ScheduledRecordingWorker>()
                .setInputData(workData)
                .setInitialDelay(delay, TimeUnit.MILLISECONDS)
                // Ensure it runs even if app was closed
                .setConstraints(
                    Constraints.Builder()
                        .setRequiredNetworkType(NetworkType.CONNECTED)
                        .build()
                )
                .addTag("recording_${channelId}")
                .build()

            workManager.enqueueUniqueWork(
                "recording_${channelId}_${startTimeMs}",
                ExistingWorkPolicy.REPLACE,
                request,
            )
        }
    }
}
```

```kotlin
@Composable
fun FocusableCard(
    onClick: () -> Unit,
    modifier: Modifier = Modifier,
    content: @Composable BoxScope.() -> Unit
) {
    var isFocused by remember { mutableStateOf(false) }

    // Animate border color on focus
    val borderColor by animateColorAsState(
        targetValue = if (isFocused) NeonCyan else Color.Transparent,
        animationSpec = tween(durationMillis = 150),
        label = "border"
    )

    // Animate scale on focus — gives satisfying "pop" on Fire TV remote
    val scale by animateFloatAsState(
        targetValue = if (isFocused) 1.05f else 1.0f,
        animationSpec = tween(durationMillis = 150),
        label = "scale"
    )

    // Animate background on focus
    val bgColor by animateColorAsState(
        targetValue = if (isFocused) BackgroundElevated else BackgroundCard,
        animationSpec = tween(durationMillis = 150),
        label = "bg"
    )

    androidx.tv.material3.Card(
        onClick = onClick,
        modifier = modifier
            .scale(scale)
            .border(
                width = if (isFocused) 2.dp else 0.dp,
                color = borderColor,
                shape = RoundedCornerShape(12.dp)
            )
            .onFocusChanged { focusState ->
                isFocused = focusState.isFocused
            },
        colors = CardDefaults.colors(
            containerColor = bgColor,
            focusedContainerColor = BackgroundElevated,
        ),
        shape = CardDefaults.shape(RoundedCornerShape(12.dp)),
    ) {
        Box(content = content)
    }
}
```

```kotlin
@Composable
fun LivePlayerScreen(
    streamUrl: String,
    streamTitle: String,
    channelId: String,
    onBack: () -> Unit,
    onChannelUp: () -> Unit,
    onChannelDown: () -> Unit,
    viewModel: LivePlayerViewModel = hiltViewModel(),
) {
    val vlcState by viewModel.vlcState.collectAsState()
    val recordingState by viewModel.recordingState.collectAsState()
    val epgCurrent by viewModel.currentProgram.collectAsState()
    val epgNext by viewModel.nextProgram.collectAsState()
    val audioTracks by viewModel.audioTracks.collectAsState()
    val subTracks by viewModel.subtitleTracks.collectAsState()

    // OSD visibility
    var osdVisible by remember { mutableStateOf(true) }
    var osdJob by remember { mutableStateOf<kotlinx.coroutines.Job?>(null) }
    val scope = rememberCoroutineScope()

    // Channel number buffer for jump
    var channelBuffer by remember { mutableStateOf("") }
    var channelBufferJob by remember { mutableStateOf<kotlinx.coroutines.Job?>(null) }

    // Show/hide OSD
    fun showOsd() {
        osdVisible = true
        osdJob?.cancel()
        if (vlcState.isPlaying) {
            osdJob = scope.launch {
                delay(5000L)
                osdVisible = false
            }
        }
    }

    LaunchedEffect(streamUrl) {
        viewModel.loadStream(streamUrl, channelId)
        showOsd()
    }

    Box(
        modifier = Modifier
            .fillMaxSize()
            .background(Color.Black)
            .onKeyEvent { event ->
                if (event.type != KeyEventType.KeyDown) return@onKeyEvent false
                showOsd()
                when (event.key) {
                    Key.DirectionUp, Key.ChannelUp -> { onChannelUp(); true }
                    Key.DirectionDown, Key.ChannelDown -> { onChannelDown(); true }
                    Key.MediaPlayPause, Key.Enter -> { viewModel.togglePause(); true }
                    Key.MediaStop -> { onBack(); true }
                    Key.VolumeUp -> { viewModel.adjustVolume(+10); true }
                    Key.VolumeDown -> { viewModel.adjustVolume(-10); true }
                    Key.VolumeMute -> { viewModel.toggleMute(); true }
                    Key.Back, Key.Escape -> { onBack(); true }
                    Key.R -> { viewModel.startRecording(channelId, streamUrl); true }
                    Key.I -> { viewModel.toggleStats(); true }
                    // Number keys for channel jump
                    Key.Zero, Key.One, Key.Two, Key.Three, Key.Four,
                    Key.Five, Key.Six, Key.Seven, Key.Eight, Key.Nine -> {
                        val digit = event.key.keyCode - Key.Zero.keyCode
                        channelBuffer += digit.toString()
                        channelBufferJob?.cancel()
                        channelBufferJob = scope.launch {
                            delay(1500L)
                            viewModel.jumpToChannelNumber(channelBuffer.toIntOrNull() ?: 0)
                            channelBuffer = ""
                        }
                        true
                    }
                    else -> false
                }
            }
    ) {
        // ── VLC VIDEO SURFACE ────────────────────────────────
        // VLCVideoLayout is VLC's native SurfaceView wrapper
        // This is where libvlc renders video directly — zero overhead
        AndroidView(
            factory = { ctx ->
                VLCVideoLayout(ctx).also { layout ->
                    viewModel.attachVideoLayout(layout)
                }
            },
            modifier = Modifier.fillMaxSize(),
            onRelease = { viewModel.detachVideoLayout() }
        )

        // ── LOADING OVERLAY ──────────────────────────────────
        AnimatedVisibility(
            visible = vlcState.isLoading,
            enter = fadeIn(),
            exit = fadeOut(),
        ) {
            LoadingOverlay(
                reconnectAttempt = vlcState.reconnectAttempt,
                reconnectMax = vlcState.reconnectMax,
            )
        }

        // ── ERROR OVERLAY ────────────────────────────────────
        AnimatedVisibility(
            visible = vlcState.error != null && !vlcState.isLoading,
            enter = fadeIn(),
            exit = fadeOut(),
        ) {
            ErrorOverlay(
                errorMessage = vlcState.error ?: "",
                onRetry = { viewModel.retryStream() },
            )
        }

        // ── OSD OVERLAY ──────────────────────────────────────
        AnimatedVisibility(
            visible = osdVisible,
            enter = fadeIn(tween(200)),
            exit = fadeOut(tween(400)),
        ) {
            LiveOsd(
                streamTitle = streamTitle,
                epgCurrent = epgCurrent,
                epgNext = epgNext,
                vlcState = vlcState,
                recordingState = recordingState,
                audioTracks = audioTracks,
                subtitleTracks = subTracks,
                channelBuffer = channelBuffer,
                onBack = onBack,
                onTogglePause = viewModel::togglePause,
                onVolumeChange = viewModel::setVolume,
                onToggleMute = viewModel::toggleMute,
                onSelectAudio = viewModel::setAudioTrack,
                onSelectSubtitle = viewModel::setSubtitleTrack,
                onStartRecording = { viewModel.startRecording(channelId, streamUrl) },
                onStopRecording = viewModel::stopRecording,
                onChannelUp = onChannelUp,
                onChannelDown = onChannelDown,
            )
        }

        // ── BUFFERING INDICATOR ──────────────────────────────
        AnimatedVisibility(
            visible = vlcState.isBuffering && !vlcState.isLoading,
            enter = fadeIn(),
            exit = fadeOut(),
            modifier = Modifier.align(Alignment.Center),
        ) {
            BufferingSpinner(bufferPercent = vlcState.bufferPercent)
        }

        // ── CHANNEL NUMBER JUMP DISPLAY ──────────────────────
        AnimatedVisibility(
            visible = channelBuffer.isNotEmpty(),
            enter = fadeIn(),
            exit = fadeOut(),
            modifier = Modifier.align(Alignment.Center),
        ) {
            ChannelNumberDisplay(number = channelBuffer)
        }
    }
}
```

## 📡 PHASE 7 — EPG SYSTEM: XMLTV FOR ANDROID

```kotlin
// core/epg/XmltvParser.kt
package com.dylandos.iptv.ultimate.core.epg

import android.util.Xml
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.withContext
import org.xmlpull.v1.XmlPullParser
import java.io.InputStream
import java.text.SimpleDateFormat
import java.util.*

data class EpgChannel(
    val id: String,
    val displayName: String,
    val iconUrl: String?,
)

data class EpgProgram(
    val channelId: String,
    val title: String,
    val description: String,
    val startTimeMs: Long,
    val endTimeMs: Long,
    val category: String?,
    val episodeNum: String?,
    val rating: String?,
    val iconUrl: String?,
)

// ─── XMLTV Parser using Android's XmlPullParser ───────────────
// This is MEMORY EFFICIENT — streams the XML rather than loading
// the entire DOM. Critical for Fire TV's 2GB RAM limit.
class XmltvParser {

    // XMLTV timestamp format: "20240115120000 +0000"
    private val dateFormat = SimpleDateFormat("yyyyMMddHHmmss Z", Locale.US).apply {
        timeZone = TimeZone.getTimeZone("UTC")
    }

    suspend fun parse(inputStream: InputStream): Pair<List<EpgChannel>, List<EpgProgram>> =
        withContext(Dispatchers.IO) {
            val channels = mutableListOf<EpgChannel>()
            val programs = mutableListOf<EpgProgram>()

            val parser = Xml.newPullParser().apply {
                setFeature(XmlPullParser.FEATURE_PROCESS_NAMESPACES, false)
                setInput(inputStream, "UTF-8")
            }

            var eventType = parser.eventType

            while (eventType != XmlPullParser.END_DOCUMENT) {
                when {
                    eventType == XmlPullParser.START_TAG && parser.name == "channel" -> {
                        channels.add(parseChannel(parser))
                    }
                    eventType == XmlPullParser.START_TAG && parser.name == "programme" -> {
                        parseProgram(parser)?.let { programs.add(it) }
                    }
                }
                eventType = parser.next()
            }

            Pair(channels, programs)
        }

    private fun parseChannel(parser: XmlPullParser): EpgChannel {
        val id = parser.getAttributeValue(null, "id") ?: ""
        var displayName = ""
        var iconUrl: String? = null

        var eventType = parser.next()
        while (!(eventType == XmlPullParser.END_TAG && parser.name == "channel")) {
            if (eventType == XmlPullParser.START_TAG) {
                when (parser.name) {
                    "display-name" -> displayName = parser.nextText()
                    "icon" -> iconUrl = parser.getAttributeValue(null, "src")
                }
            }
            eventType = parser.next()
        }
        return EpgChannel(id, displayName, iconUrl)
    }

    private fun parseProgram(parser: XmlPullParser): EpgProgram? {
        val channelId = parser.getAttributeValue(null, "channel") ?: return null
        val startStr = parser.getAttributeValue(null, "start") ?: return null
        val stopStr = parser.getAttributeValue(null, "stop") ?: return null

        val startMs = parseTimestamp(startStr) ?: return null
        val stopMs = parseTimestamp(stopStr) ?: return null

        var title = ""
        var description = ""
        var category: String? = null
        var episodeNum: String? = null
        var rating: String? = null
        var iconUrl: String? = null

        var eventType = parser.next()
        while (!(eventType == XmlPullParser.END_TAG && parser.name == "programme")) {
            if (eventType == XmlPullParser.START_TAG) {
                when (parser.name) {
                    "title" -> title = parser.nextText()
                    "desc" -> description = parser.nextText()
                    "category" -> category = parser.nextText()
                    "episode-num" -> episodeNum = parser.nextText()
                    "rating" -> {
                        if (parser.next() == XmlPullParser.START_TAG && parser.name == "value") {
                            rating = parser.nextText()
                        }
                    }
                    "icon" -> iconUrl = parser.getAttributeValue(null, "src")
                }
            }
            eventType = parser.next()
        }

        return EpgProgram(
            channelId = channelId,
            title = title,
            description = description,
            startTimeMs = startMs,
            endTimeMs = stopMs,
            category = category,
            episodeNum = episodeNum,
            rating = rating,
            iconUrl = iconUrl,
        )
    }

    private fun parseTimestamp(raw: String): Long? {

            // Format: "20240115120000 +0000" — space before timezone

        } catch (e: Exception) {
            null
        }
    }
```

### 12.1 Memory Management Strategy

```kotlin
// core/MemoryManager.kt
package com.dylandos.iptv.ultimate.core

import android.app.ActivityManager
import android.content.ComponentCallbacks2
import android.content.Context
import android.content.res.Configuration
import dagger.hilt.android.qualifiers.ApplicationContext
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import javax.inject.Inject
import javax.inject.Singleton

@Singleton
class MemoryManager @Inject constructor(
    @ApplicationContext private val context: Context,
) : ComponentCallbacks2 {

    private val activityManager =
        context.getSystemService(Context.ACTIVITY_SERVICE) as ActivityManager

    private val _memoryPressure = MutableStateFlow(MemoryPressure.NORMAL)
    val memoryPressure: StateFlow<MemoryPressure> = _memoryPressure

    // Called by Android when memory is low
    override fun onTrimMemory(level: Int) {
        when {
            level >= ComponentCallbacks2.TRIM_MEMORY_RUNNING_CRITICAL -> {
                _memoryPressure.value = MemoryPressure.CRITICAL
                // Emergency: clear all image caches
                clearAllCaches()
            }
            level >= ComponentCallbacks2.TRIM_MEMORY_RUNNING_LOW -> {
                _memoryPressure.value = MemoryPressure.HIGH
                // Clear non-essential caches
                clearLogoCache()
            }
            level >= ComponentCallbacks2.TRIM_MEMORY_RUNNING_MODERATE -> {
                _memoryPressure.value = MemoryPressure.MODERATE
            }
            else -> {
                _memoryPressure.value = MemoryPressure.NORMAL
            }
        }
    }

    override fun onConfigurationChanged(newConfig: Configuration) {}
    override fun onLowMemory() {
        _memoryPressure.value = MemoryPressure.CRITICAL
        clearAllCaches()
    }

    fun getAvailableMemoryMB(): Long {
        val info = ActivityManager.MemoryInfo()
        activityManager.getMemoryInfo(info)
        return info.availMem / (1024 * 1024)
    }

    fun canStartNewRecording(): Boolean {
        // Only allow 2nd recording if we have at least 400MB free
        return getAvailableMemoryMB() > 400
    }

    fun canStartThirdStream(): Boolean {
        // Only allow 3rd pipeline if we have at least 600MB free
        return getAvailableMemoryMB() > 600
    }

    private fun clearLogoCache() {
        // Clear Coil image cache
        // coil.imageLoader(context).memoryCache?.clear()
    }

    private fun clearAllCaches() {
        clearLogoCache()
        // Clear any other in-memory caches
    }
}

enum class MemoryPressure { NORMAL, MODERATE, HIGH, CRITICAL }
```
